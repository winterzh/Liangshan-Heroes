# 2026-09-26 战斗与图鉴头像统一、四名将领补图

## 玩家可见变化

战斗左下角、选中单位图标、英雄栏、训练图标与图鉴统一经 `Art.ui_portrait_texture` 读取同一人物的标准头像。此前战斗会优先读取便装、被缚、获救等剧情变体的旧图，导致同一个人与图鉴画风不同。本轮给已登记的人物变体绑定所属人物，错配时拒绝显示，避免把另一个人的脸套过来。

新增四幅 1254×1254 原生 PNG，沿用晁盖参考图的暖灰褐纸纹与工笔厚涂处理，各自保留识别特征：

| 人物 | 独立特征 |
| --- | --- |
| 卢俊义 | 修长面形、整齐长髯、银甲白披风 |
| 关胜 | 赭红长脸、长直黑髯、绿袍绿巾 |
| 秦明 | 宽圆脸、浓短卷须、红巾与铜甲 |
| 呼延灼 | 方正成熟面形、短方须、深色铁盔与双鞭 |

新图来自内置 `image_gen`，按生成原始字节保存至 `assets/characters/hero_portraits_commanders_20260926/`，没有本地重画、滤镜、缩放或裁剪。提示词、生成标识、风格及身份参考、生产 SHA-256 位于 `tools/contracts/hero_portraits_commanders_20260926/`。脸型、服色等是游戏美术选择，不作为原著逐字考据结论。

## 实现边界

- 人物归属表位于 `CampaignArt.PORTRAIT_OWNERS`，与已有程序化被缚归属表共同查询；支持 `lin_chong_bound` 等现有身份别名。阮小二沿用实际关卡注册的 `ruan_xiaoer → ruan_brother` 标准取图关系。
- 变体的世界身体、服装与动作仍由原资源链读取。`Art.avatar_texture` 保留剧情原图的素材预览/来源契约语义；玩家界面调用新的统一入口。
- 城镇路人、建筑、刑台等保留各自图标。已有旧图集仍有其他角色引用，继续保留。
- 本轮统一人物在两个界面的取图，并新增四人美术；没有宣称所有旧人物头像均已重绘。

## 复现

在源码根目录运行，Godot 通过现有本地配置解析：

```powershell
python -X utf8 -B tools/run_hero_portraits_qa.py --work-root <工程外QA目录> --contract tools/contracts/hero_portraits_commanders_20260926 --ui --run
```

工具冻结生产输入，使用共享引擎锁和私有用户目录，导入后渲染实际图鉴与 256/96/64/32px 预览。附加 `tools/ui_portraits_qa.gd` 在真实黄泥冈 Battle/HUD 中冻结战斗、选择人物和变体，检查左下角控件、错误归属拒绝、八人不同源图及物件/路人/世界动作保留。截图是实际引擎控件；循环变体是 UI 专项夹具，不声明逐关通关、移动端真机或战斗平衡验收。
