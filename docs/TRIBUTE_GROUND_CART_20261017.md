# 黄泥冈劫取后的地面财物车（2026-10-17）

本批把已取走、送达或搬运者倒下后重新落地的财物，与刘唐上一批推车图统一。押送队的原始担子不提前变成车；酒计完成本身也不会触发切图。未改关卡目标、任务回调、阵营、伤害、寻路、存档字段或人物身体。

原著第16回七人把金珠宝贝十一担装入七辆江州车，遮盖后推下冈：[原文](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第016回)。单轮结构、木色和绳布细节属美术补足；当前三目标抽象、强夺分支、其他角色肩挑和现行文字仍须继续修正，本批不宣称七车十一担已完整对应。

## 接入

`scripts/campaign_tribute_cart_visual.gd`只匹配第1关两份既有脚本、当前实际世界单位与原level.bundles成员，再读取该编号已取走/已送达事件或已有掉货次数。当前短版部署后实际使用tribute_load_alpha_20260906且移除了旧环境路由，因此要求该variant与setup_def.campaign_object同时精确匹配、无额外环境路由；旧完整版只接受原tribute_load/tribute_load路由。原生本批验收的是当前短版，旧完整版分支仅保持源码兼容。无新增Unit实例字段、持久元数据或状态编解码字段。其他关卡、普通物件、枣车和仅冒用相同标识的非任务成员均被排除。

4个物件专用Atlas使用上一批未经改像素的`cart_only.png`，不调用刘唐身体路由冒充物件，也不借用其人物身份。只通过Godot区域、虚拟透明边距和等比显示把车轮接触点放在物件逻辑原点，保留与推车时相同的画面比例。只读原图alpha测量visible_top，把现有单位血条/名字放在车身上方，避免挡住财物。原图、原始提示词和引用SHA继续在上一批来源目录。Art强缓存保留RID，Unit世界图/预览和WorldShadow轮廓使用同一物件、尺寸、地面点；四向不额外镜像。
