## 数据与边界

_vision 保存未探索/已探索/当前照亮三种状态，_sight_now 保存当次视野，_reveal_t 保存逐格临时侦察剩余秒数，_fog_t 保存下一次迷雾处理的相位。重新调用 _fog_pass 会推进时间并重新计算可见性，不能用它代替恢复。

两份 PackedByteArray 经明确的有界整型数组运输，验证每个字节的域后才重建 packed 数组，拒绝隐式截断 -1、256、浮点或 bool。_reveal_t 使用基础 codec 的 PackedFloat32Array 位表示，_fog_t 保持原 float64 位；不重置相位或根据退出期间的墙钟扣时间。所有七值共用一次完整值树编码预算。

宽高各限 1–256、乘积最多 4096；先核对轴和乘积，再分配或遍历数组。60×60 是标准驻守夹具，不是全项目固定尺寸。解码还要求外层提供独立、已经验证的期望尺寸，不能把记录自己的宽高充作依据。禁用且未初始化的三个空数组可以保留；已初始化数组必须完整匹配格数，不自动清空或补齐。

本层只检查局部结构。lit_cells 的独立高亮倒计时、Unit 可见状态、图与业务一致性、地图导航和显示资源重建仍由后续完整快照负责。内容指纹是调用方传入/比对，尚未构成有效整局定义校验。所有接口保留 restore_ready=false。
