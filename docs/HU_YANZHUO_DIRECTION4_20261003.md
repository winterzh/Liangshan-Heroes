# 呼延灼身份与四向基础动作 · 2026-10-03

按最新计划首先处理呼延灼：将旧刺锤、红缨绿巾造型改为两条实心八棱钢鞭、角铁幞头、黄罗抹额、黑袍乌油甲与黑马白蹄，身体和半身头像共用这组身份。脸部保留成熟宽脸、浓眉和黑长须；造型依据[第五十五回原文](https://ctext.org/wiki.pl?chapter=810331&if=en)，绘图是游戏中的解释，不声明历史服装复原。

## 接入方式

- 九份生产原生 RGBA PNG 保存在 `assets/characters/hu_yanzhuo_direction4_20261003/`；只复制生成字节，未本地抠图、缩放、镜像或改写位图。透明像素比例超过 35%，头像约 35%；纹理边缘在引擎背景上另作目检。
- 八张动作源选取 32 个独立姿势，以 20 个 SpriteFrames/AtlasTexture 资源接入 SE/SW/NE/NW 的待机、行走、攻击、受击和死亡。行走为两帧换步；攻击为起手、打击和待机恢复；死亡为倾倒、落地末帧及停留。保持现有近战命中时机、数值、物理位置、选择圈与死亡生命周期。
- 攻击原图的一格东北打击错误朝西北，保留原字节并明确排除，实际引用独立重画的 `ne_strike.png`。死亡前两行末帧按马头方向选择 SE/SW，未反射图像。脚点、留白和视觉大小只由 TRES 参数补偿。
- 首次图形检查虽自动通过，目检发现密排行走与攻击起手越过等分边界，产生邻格碎片；行走 A/B 和起手另绘为留白更大的四向图。旧行走候选留在来源契约目录并拒绝入库；旧攻击左列和错误东北格明确排除。死亡改按完整姿势范围采样，避免脚点和大小受邻格像素影响。所有原始 PNG 字节仍保留。
- `scripts/art_db.gd` 的独立头像指向新半身图；图鉴、战斗选中面板和角色 UI 共用。`scripts/unit.gd` 将呼延灼纳入已有独立动作保护，避免旧整身挥动/武器拖影叠加；仅在无剧情变体且实际使用独立四向攻击帧时生效。
- 旧身体和旧头像原图继续作为来源及回退保留，不覆盖历史图片。生成提示、标识、引用 SHA 和采样区域见 [来源契约](../tools/contracts/hu_yanzhuo_direction4_20261003/README.md)。

## 限制与后续

本批提供呼延灼基础四向动作和身份一致性，不将低帧数换步等同于连续高帧率动画。未增加剧情换装、变更平衡、运行完整连环马通关、保存恢复、长测、手机/平板或全套多尺寸 UI 验收。后续核心六人的独立四向、晁盖服饰差异及全库美术继续开放。
