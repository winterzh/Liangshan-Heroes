## 玩家流程

1. 选择鲁智深，右键林边地面暗随。新增选人捷径和北松林/南芦丛镜头定位，均不代走；上方继续显示距离，左侧提示当前操作。押送队自行前进，不等玩家点任务。
2. 北路近、正常拦棍34秒；南路远、42秒。贴近0.8秒先警告，退开能消退；持续2.4秒暴露后只剩24秒。检查点暂时跟丢只提示追赶，到树前追上仍可恢复暗随。未及时跟上者到树下仍有最后24秒救援窗口，错过完整暗随演义，但可以救人；倒计时用完才失败。
3. 等薛霸举棍，选鲁智深右键现场拦棍标记，停留0.8秒。也可直接攻击解差，双方真实交手，留命制服两人后走回林冲身旁。救人要求鲁智深实际在100距离内；不再远处打倒解差后隔空解缚。
4. 解缚保留林冲实际位置及恢复延迟，不把人搬回预设松树坐标；照料结束也不瞬移四人凑队形。获救林冲为非战斗伤员，不攻击、施法或提供战斗光环；局外林冲定义不受影响。
5. 救人后同时开放可选歇脚和结队出林。任一队员的真实移动指令会带上幸存队伍，鲁智深在前、解差照应林冲；S停止也传播到全队，之后可换路线。没有玩家命令，四人原地等待。
6. 林冲、鲁智深和所有幸存解差到林口后通关。歇脚、留命警诫并四人到齐可完成完整演义；直接离开不会虚记歇脚。解差实际阵亡时演义失败，核心仍能由幸存队伍完成；鲁智深或林冲死亡明确失败。

## 同行和现场任务的修正

任务的一次性输入凭证会在林冲开始办理时被整组消费，不能再将它用作剩余路径的唯一授权。现在关卡记录玩家命令实际生成的单位指令序号；同伴可走完已经下达的那条路，而新脚本移动、自动派遣、过期任务仍不能冒充玩家。没有重新补发任务凭证，因此不会用一次右键连办歇脚与出林。

歇脚、出林需林冲走到旗标48距离内才开始办理，开始后允许最多16距离的同伴碰撞偏移，避免伤员被轻挤出界便丢失指令；重新下令仍立即取消，其他任务默认没有该容差。获救人员保留现场位置，实际下令后需在3秒内走近成队，随后维持原有96单位行进间距上限；初始散站距离另列在QA，不以瞬移凑齐。歇脚只有队伍实际到齐才给予一次治疗、记事件；有人未到时恢复按钮与旗标，可再次办理。原先先记成功再检查队伍会导致任务被消耗、后续入口不开，这一分支已修正。
