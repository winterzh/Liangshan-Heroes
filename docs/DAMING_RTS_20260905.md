# 大名府：城外经营与城内接应

当前菜单“智取大名府”使用 `scripts/levels/level8_daming_rts.gd`。沿用 `level8`、索引7和原著章节顺序；旧 `level8_dongchangfu.gd` 保留地图与场景来源，旧逐步剧情回放不能证明新入口。演义合同版本为2，仍为三项；已有存档印章按共享规则保留。

## 玩法与操作

城外前营从开局就可采集、建造、训练和出击。吴用领军，宋江留在梁山调养；时迁已带火种入城，柴进、乐和已由蔡福安排乔装，不再先完成多段换装读条才能放开外军。内外两线共享同一战场时间，阶段不清空建筑、人口、军队或钱粮。

1. 经营前营，补兵并准备器械。西侧外营是来袭来源，先拆可以保后路并取得附近大资源点，也可以直接向南门推进。
2. 内应路线：柴进与乐和到牢前，选柴进右键“受验”旗标；放行后手动带二人走入内院等候。时迁到翠云楼举火，提供90秒调兵机会。任务按钮只定位；普通右键办理，A移动不办理，改令会取消。
3. 鲁智深或武松与至少两名战友到南门，清掉近处守军后右键夺门标记，可打开完整城门。强攻路线则用真实攻击破门，无无敌盾；控制牢前后可以强开牢院，仍能完成核心营救。
4. 先清牢前抵抗、拆牢区箭楼，再入牢开枷。卢俊义、石秀变成可选的伤员，仍无攻击与技能，不自动行军。选二人并带兵护送到城外接应地，不要求杀光全城；只到一人不会胜利。前营或任一囚徒阵亡即失败。

乔装使用共享隐匿索敌机制。与可达的敌方战斗人员相距不足68像素并持续2.5秒会暴露；离开后未满的警戒进度会回落。攻击或施法也会破除隐匿。暴露者在蔡福家停留3秒、附近无敌人即可重新乔装；途中离开会取消恢复。新增蔡福家、获救后接应地的纯定位按钮，便于寻找地点，不选人、不派人、不生成额外读条任务。关键内应阵亡只关闭相应可选路线，外军仍可强攻。

## 经济与敌军

地图60×66，初始300金/200木、人口19/24，前营、兵营、6工人、3名外军英雄、2枪2弓和3名内应。复用共享刀枪弓马、民居、仓库、集市、箭楼、作坊、撞车、投石车和英雄成长；塔、普通兵、外军英雄的生命、攻击和造价未为此关改写。聚义厅限制本章训练名单，内应与伤员不占战斗人口且不能重复招募；退出后覆盖不泄漏到驻守。

两处官军营地约115秒后开始补军，之后每38秒检查，按共享刀/弓成本扣除独立金木。官军开局160金/240木，有两名真实采金工人，木材预算有限；在场补军最多12人。拆营停止该处后续生产，摧毁留守大营停止全部补军，已经出场的部队保留。南门和牢区各有一座共享箭楼，普通守军会迎敌、短追并回岗位。

火号调走开局即存在的6名机动守军，并暂停城内营补军90秒；城西营继续出兵，时间到后城内补军恢复、原守军回防。另一支6人留守队也从开局存在，获救者离开牢区后先预警15秒再追击。没有触发后凭空生成免费外军或无限追兵。可以提前打掉这些兵。

## 本轮修复与表现边界

- 城门两脚按原图接地点映射到南墙端点，屋柱保持竖直，独立高度与当前城墙匹配；关闭时用门体局部绘制的木门扇填上原素材的开放门洞。位图未修改。不使用的旧偏门封成墙，门牌挪开，不再展示一个无法办理的旧入口。
- 牢内集合点与开枷标记分开，普通集合移动不再误触救人。打开/攻破门同步释放实际导航阻挡；已破门后再举火不新增失效夺门任务。
- 共享远程追击现在允许走到城墙外合法射程内。原普通寻路仍要求全程可达；仅远程追击在普通路径为空时查询可达的部分路径，并验证终点确实在射程内。近战、H原地据守、陆水边界不变。实现参考 [Godot 4.6 AStarGrid2D 官方 API](https://docs.godotengine.org/en/4.6/classes/class_astargrid2d.html)，避免以实心格作为部分路径目标；游戏行为另以实际单次攻击指令验证。
- 灯楼火号与两名囚徒被缚/获救造型复用现有已入库资源。开门仍使用通道释放与门单位退出表现，未制作完整门楼开扇动画；现有城墙与门楼的材质统一度仍可继续改善。

三项演义分别核对内应入牢举火、完整城门接火号、外军夺门及内应开枷。提前解枷、破门或强开牢院可以完成核心目标，但相应演义条件落空。这是可选路线结果，不能用它强制玩家照唯一顺序通关。
