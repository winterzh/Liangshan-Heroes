# Steam Windows 战役操作与启动优化

《水浒英雄传：八幕战役》Windows 正式分支已更新到 Build 26873421，发行来源为 [ee9f29f5](https://github.com/winterzh/Liangshan-Heroes/commit/ee9f29f5f8124166ce1492b30094fea39fbf6c8e)。

- 黄泥冈可批量派待令空车装货，也可统一派已装货的车出冈。已有装货、改道和据守命令继续执行。
- 野猪林可带队歇脚或出林，连环马可派投石车绕南侧。江州可送获救者登船及撤回岸上同伴，祝家庄、大名府和高俅关分别有直接归营、撤伤员和押解指令。
- 兼容旧档可继续。续玩后存档槽未变化时，再次保存退出可直接保存。
- Windows 游戏数据独立装载，减少启动等待。部分地图改善资源准备，黄泥冈开场省掉一次未使用的头像读取。
