# 祝家庄：损兵后的补员与主动定位

本轮承接已定稿的[玩法方向](GAMEPLAY_DIRECTION_20260914.md)，补充损失普通兵后的恢复引导。玩家仍自行选择招募、集结和进攻办法；不改变经济、伤害、守军、人口、训练时间或关卡路线。

## 玩家行为

- 我方存活普通兵归零时，在右上角显示恢复提示，任务面板收起时也可见。英雄、工人、伤员、俘虏、召唤物和器械不算普通兵；驻军内的普通兵仍算存活，不误报损失。
- 有普通兵在训练时显示训练状态；出口受阻、资源或人口不足、兵营研究中、施工中、无兵营和无工人分别说明对应情况。
- “查看 · 兵营”动态寻找现存兵营；“查看 · 前营”定位现存前营。两按钮只移动镜头，保留当前选择、单位命令与任务办理，不自动选建筑、训练或出兵。
- 补出第一名普通兵即收起提示；核心目标已可收军或战斗结束时隐藏。无重复 toast、强制镜头或强制通关步骤。
- 新提示按既有流程提供简中、繁中、英语、日语，并支持即时切换。

## 实现边界

`scripts/zhujiazhuang_recovery_hint.gd` 是 HUD 下的独立派生面板，关卡每次现有 0.5 秒战略更新时刷新；没有新增 Level 保存字段，也不向任务注册动作或地图旗标。面板自身检查终局并隐藏，避免关卡停止更新后残留。

状态从当前单位、兵营与生产队列推导；恢复世界后可重建提示，不宣称新增玩家存档或保存了面板本身。现有玩家中途保存/继续的开放状态不变。

之前的代理试玩中，`stage_army=0` 排除了全部英雄；最后一张黑雾图由观察脚本主动定位到未探索区域后截取。故本轮以“普通兵损失后可恢复”为问题，不把旧记录解释为全军覆灭、镜头故障或“裸冲必败”。提示出现和代理操作不等于无攻略真人理解、趣味或平衡验收。
