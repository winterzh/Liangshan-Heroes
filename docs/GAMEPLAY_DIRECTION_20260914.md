# 水浒玩法方向（RTS 调研定稿）

日期：2026-09-14。本文件是多轮同类型 RTS 调研后的**最终玩法方向**，日常设计与评审以本文件为准。  
过程样本见 `GAMEPLAY_STUDY_RTS_20260914.md`、`AOE_SERIES_STUDY_20260914.md`；先前十二条清单作废，由本文件替代。

约束不变：不魔改，能行就行，不行就算了。原著名场面决定每关的问题；不硬加原著没有的军事行动或经营。

---

## 一句话方向

**好汉带队，通过经营、侦察和战术解决不同战局；原著名场面决定每关的问题。**

玩家最终感受应是：

> **我能看懂局势、作出选择，并感受到自己的计划改变了战局。**

---

## 七条精华

| 参考 | 精华 | 水浒落地 |
| --- | --- | --- |
| 帝国时代 | 经营与战争相互制约 | 祝家庄先抢矿能支撑后续攻城，但要分兵护矿；直接进攻更快，却可能补兵吃紧 |
| 魔兽争霸 | 英雄改变部队打法 | 好汉突破、牵制、指挥，为部队创造机会；普通兵承担阵线、保护和持续作战 |
| 星际争霸 | 每关换一个主要战场问题 | 江州重分兵营救；祝家庄重攻城断援；连环马重阵形反制；大名府重内外协同；高俅重水陆支援 |
| 英雄连 | 位置和接战方式有价值 | 枪兵守窄口、弓手利用射界、骑兵绕后、器械得保护；混编与调动能带来可见收益 |
| 亿万僵尸 | 进攻与防守互相牵动 | 出门清营、断粮可降低后续压力，但主力离家留空当；何时出门、何时回防由玩家判断 |
| Northgard | 经济压力能提前理解 | 能看出缺的是补员、器械还是后方保护，并有时间调整；避免突然刷出一批敌人宣判失败 |
| 红警／C&C | 目标清楚、关卡有记忆点 | 每关一句明确目标 + 一个可玩的原著名场面（内应开门、钩镰破骑、火船破阵等） |

**关键在连接**，不是七条并列。以祝家庄为例：

侦察发现南营持续增援 → 决定分兵断援 → 正面暂时吃紧，靠英雄和守军撑住 → 南营被毁后敌方补兵确实减少 → 再投入器械总攻。

侦察提供信息，经营提供军力，英雄帮助执行，地图目标改变战局。玩家会感到：**这个计划是我想出来的，而且起作用了。**

说明：七条**按关卡需要组合，不要求每关全部具备**。上述链条是「玩家计划能够产生效果」的例子，**不能变成强制照做的通关流程**；正攻等其他计划仍可成立。

## 三个取舍

1. **短篇突出人物、智谋与关键操作。**  
   黄泥冈重智计，野猪林重救援护送，快活林可以重拳脚与读招，各自成立即可。  
   篇幅由有效选择决定，不强行补兵营，也不靠跑腿拖长。

2. **多解法要有不同代价。**  
   正攻、断援、内应可以通向同一结局，但应分别影响时间、损耗、准备和操作难度。  
   无需把每条路做成一样划算。

3. **操作和容错支撑策略。**  
   命令反馈、寻路、威胁提示、暂停、重试和续玩，应让玩家有机会理解局势、执行计划、从失败中调整。

## 对八关的含义（非硬模板）

- 类型差异应被真人**感到**，不必在菜单上贴满标签。  
- 「一关一新机制」「必须轮换」「必须两条路线」可以灵活处理；例外须写明理由并经用户确认。  
- **软化的是设计公式，质量底线仍然保留**：操作可靠、提示可理解、失败有合理反馈、保存恢复符合承诺，仍应具体验收。  
- 快活林：在原著饮酒、挑衅、拳脚、交店内找「不同计划与代价」；撑不起独立 RTS 关则由用户决定插章/降级/删章，不硬凑。  
- 经典 30 波与战役并列：推守钟摆、压力可读，不抢战役的「故事主轴」。

## 硬约束（不可用「软目标」例外）

1. 不魔改原著；玩家始终站在梁山叙事主轴。  
2. 技术底线：寻路、误触、崩溃、存档/续玩不坑人。  
3. 公告与商店描述不夸大未开放/未验收功能。
