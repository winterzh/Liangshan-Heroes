# 实际战斗Steam累计击杀与恢复防重

Battle的敌方非建筑死亡回调现在只在FIGHT阶段增加_steam_valid_kills，并把累计值传给SteamService.record_kill(run_id, total_valid_kills)。战后展示kills仍沿用原规则，不能拿包含非战斗阶段死亡的展示数替代有效统计。新累计值随战斗世界恢复；SteamService保留当前局已计入的高水位，只把超过它的差值加到统计，重复、较低值、错误局编号、已终局、账号切换和非法类型/范围不会重复计数。差值一次加总并饱和到2147483647，不为大差值逐次循环或在死亡回调做磁盘IO。

例如世界保存于累计2击杀，此后服务已计到5；恢复那个世界再击杀至3、4、5不会重加，达到6只加1。这个同进程行为已在真实Battle死亡信号和完整世界替换中验证。服务高水位当前仍是进程内存，上一批独立持久局记录尚未接到SteamService；因此本批不证明跨进程防重、持久outbox或玩家继续入口已完成。
