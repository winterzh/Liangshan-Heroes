## 性能、稳定性与交付

两会话已接入导航、兵群分离、地图投影、树冠/芦苇/寨墙、重绘和索敌等优化。另一个会话收尾时的正常200敌压力测得 **24.99 FPS / P95 76.973ms**，整体性能仍不合格；本轮没有重测压力FPS，不能把局部函数收益换算成整场提升。见[索敌测量](ENEMY_CANDIDATES_20260906.md)。

本轮合并后的 **1,244项运行检查 + 485项资源检查 = 1,729项通过**；36个既有宋江/林冲排帧资源复现无差异，孙立草稿50个哈希条目复核一致，Godot4.6.3真实渲染启动通过。这些不替代真人八关、30波、30分钟以上稳定性或商业素材来源验收。
