## 性能、稳定性与交付

两会话已接入导航、兵群分离、地图投影、树冠/芦苇/寨墙、重绘和索敌等优化。此前短压力窗口为 **24.99 FPS / P95 76.973ms**，见[历史索敌测量](ENEMY_CANDIDATES_20260906.md)。当前M1已建立15个至少60秒窗口：固定驻守全窗FPS中位78.42，但最差10秒仅17.87—22.79FPS，后段清敌后的空闲会抬高平均值；整体流畅度仍未通过。这些不同窗口不能直接相减当成优化收益，详见[当前基线](POLISH_BASELINE_20260906.md)。

统一版本合并时 **1,244项运行检查 + 485项资源检查 = 1,729项通过**；36个既有宋江/林冲排帧资源复现无差异，孙立草稿50个哈希条目复核一致。当前M1另完成126项长窗口完整性、25项模式和88项短切换检查；旧性能入口仍保留6项门槛/缺基线失败。这些不替代真人八关、30波、30分钟以上稳定性或商业素材来源验收。
