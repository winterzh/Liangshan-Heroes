# 局部恢复模块接入与原生验证

2026-09-07，在 `61f8f557cb19e5f6483f468ba3435767a2108584` 稳定编号基线上，五份已验证脚本接入工程：新增根状态、剩余效果、物品施法队列和共享特效图四个模块，以及 Battle 的恢复专用 ready 闸和失效引用修复。四份新模块的 Godot UID 来自实际受测私有工程。正式局部恢复组件从 15 项增至 19 项，尚无玩家“继续本局”入口。

## 本批实际行为

`run_battle_root_state.gd` 保存当前 170 个 Battle 声明中的 105 个根字段，其余 65 个明确交给外部世界、单位、效果、RNG、关卡和 UI 适配。保留非空缓存、英雄成长/库存、稳定编号、视口 Rect2、短暂输入时间原点与引用图。原生验证发现英雄/物品配置键错误共用了十进制实体编号校验；已拆开两个域，保持实体引用严格校验，并用实际英雄统计创建器和非数字物品键覆盖修复。

`run_remaining_effect_state.gd` 处理兽群、四种技能弹道模式和陷阱三个权威数组。`run_item_cast_flow_state.gd` 处理等待/走近物品施法两个队列，保留物品 UID、槽、目标、过期引用和先后顺序。Battle 的两个物品消费者拒绝已释放目标，两个技能弹道消费者将已释放施法者转换为 typed API 接受的 null；这些路径有原生案例。

`run_visual_graph.gd` 当前显式支持 13 类真实特效及普通 Node2D 容器：Bolt、TrapMarker、BeastStampede、HitSpark、FloatLabel、Meteor、GroundFire、Ward、ArrowShot、ArrowRain、Flameburst、Ability、BuildingCollapse。保留节点顺序、变换、名称、激活属性、计时、轨迹/粒子、真实单位引用和受信纹理。10 个恢复专用 ready 闸避免重新抽粒子随机数或重置时间。GroundFire 必须绑定原始 Battle 计数及 tree_exited 回调；建筑纹理只接受受信宿主注册的实际资源。

最初视觉失败先定位为 Dictionary 新键以点语法产生 StringName；改用明确 String 键，通用值 codec 仍严格拒绝 StringName。随后 R3/R4 的 8 例只差 FxRoot 名称：测试将同名根放在同一父节点，Godot 自动改名。R5 为两图使用独立同变换父节点，保留完整名称和字段比较。所有原始失败均保留。

一次物品运行因 ROOT 传错 suite/prefix，原生断言通过但 runner 判失败；随后使用相同候选与正确参数重新完整运行通过。没有将误调用的失败收据改成成功。根状态 R1 的 HERO_RECORD 失败与 R2 修复同样独立封存。
