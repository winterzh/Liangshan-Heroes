# 小更新：任务目标面板支持收起

八个战役的任务目标面板现在默认收起，点击“任务目标”即可展开，再点“收起任务”即可关闭详情，为战场留出更多视野。

收起期间任务进度照常更新，原来被面板遮住的区域也可以正常点击和框选。

感谢大家的反馈，祝各位好汉征战顺利！
