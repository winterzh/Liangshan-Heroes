# 可选精简特效与飞斧释放目标修复

2026-09-06，M2C。设置中新增“显示 → 特效细节 → 标准 / 精简”，默认标准。精简档已实现并通过本批行为、实际菜单输入、重启和旧配置兼容复验；压力性能仍未通过持续 30 FPS 的中间目标。原始证据和失败记录见 [QA 索引](../qa/reduced_effects_20260906/README.md)。

## 玩家行为与实现

从主菜单“更多 → 设置”或战斗暂停中的设置进入，向下滚动到“显示”。切换立即影响绘制，返回或 Esc 关闭设置时保存；从暂停打开设置，关闭后战斗仍暂停，再选择继续。设置面板提高到既有模态界面使用的 z=300，修复战斗 toast 盖住面板的问题。

`settings.cfg` 的 `[show] effects_quality` 只接受 `standard`、`reduced`；缺失、类型错误或非法值回到标准。字段尚不存在的旧 Settings 自动加载组合会隐藏新选项，绘制保持标准。本批真实旧 Settings 检查在当前桌面工程的独立源码副本启动，不代表历史 Android APK/PCK 已通过。

精简档只调整五类绘制：关闭装饰浮尘、关闭行走尘土绘制、削减普通/重击的次要射线、地火不画余烬、飞斧不画三个拖尾点。火焰和作用区域、斧体、命中白色中心及重击核心保留。装饰对象的生成、随机数消耗、生命周期和完整非绘制回调保持；不复用旧 `_lite_fx` 开关，不改变物理频率、托管、迷雾、伤害或寻路规则。

另有一项独立错误修复：`LiBrawnAxesFx.resolve_hits` 和 `_draw` 原来先把已释放对象赋给带 `Unit` 类型的变量，再判断有效性；赋值已经抛错，后续目标漏结算，特效可能无法删除。现在先用 Variant 检查有效性，再赋类型。保留原有死亡、驻军、剧情单位及护盾等条件，不能把这一修复描述成“所有非绘制代码完全未变”。

## 复现与下一步

普通启动仍用 `Play.cmd`。公共 QA 命令、私有用户目录和严格旧源合同见 [工具说明](../tools/contracts/reduced_effects/README.md)。

性能入口新增 `--effects-quality standard|reduced`，默认显式标准。探针在配置、开始、结束及既有轨迹采样时点核对实际值；报告 schema 2 保存真实档位和验证状态，混合/未验证档位不能汇总为合格基线。旧 schema 1 未记录档位时标成 `legacy_unrecorded`，不反推标准，不改历史成绩；十项有效/缺失/损坏元数据反例检查通过。

```powershell
python tools/run_reduced_effects_qa.py --run --suite all
python tools/run_reduced_effects_qa.py --run --suite freed-target-boundary
python tools/run_polish_performance.py --cases defense200 --camera fixed --effects-quality standard --repeats 3 --seconds 60
python tools/run_polish_performance.py --cases defense200 --camera fixed --effects-quality reduced --repeats 3 --seconds 60
```

Godot 路径通过既定参数或本机配置提供；基准独占引擎，自动镜头另批运行。正式窗口使用公共探针和更严格的串行外层助手，助手原文一并归档。下一步依据 [物理成本诊断](PHYSICS_COST_20260906.md)继续分离/Unit 热点与首次资源成本归因；M2、M3 续玩及 M5 长时验收继续开放。本批仅同步 stable 源码，不包含新发布。
