# 阮小七人物与战斗美术卡（2026-10-15）

## 已回读的一手来源

2026-10-15夜直接回读百二十回本[第十五回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第015回)131–136行及[第十九回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第019回)123–130行。第十五回写“疙疸脸横生怪肉，玲珑眼突出双睛”“腮边长短淡黄须，身上交加乌黑点”；初见戴遮日黑箬笠、棋子布背心、腰系生布裙。第十九回迎捕盗官军时戴青箬笠、披绿蓑衣、手撚笔管枪；之后入水拖住何涛、与阮小二配合，是水军与渔人本领，不能由“活阎罗”绰号推成亡魂法师。

## 普通战斗身份目标

使用第十九回水战衣装作为普通战斗参考：青色旧箬笠、朴素绿蓑衣、笔管枪。保留第十五回面貌特征，形貌粗犷、面部凹凸和突眼、长短淡黄胡须，肤色自然风晒；裸露手臂上的乌黑点仅依据原文，不加纹身、永久刀疤或怪物皮肤。箬笠下的发式、蓑衣具体编织、枪头尺寸/杆材、裤脚/赤足等未逐项写明处为朴素美术补足，不宣称完整历史复原。

同一人必须能从头像、四向身体与动作辨认。画像不得沿用旧深色山羊胡、年轻俊脸、三叉戟、水浪图腾、甲胄、兽皮、鬼魂或死神镰刀。普通战斗不能穿征方腊后误戴的冠袍。

建立待机、四步态、攻击、两帧受击及四阶段普通倒地的四向资源；笔管枪是唯一兵器，切忌多出第二根杆或把蓑衣编织画成金属甲。普通倒地是失败玩法，不演原著六十岁自然寿终。
