# 黄泥冈：押队停靠与白胜自行入场

用户实玩截图指出押送者互相挤、白胜留在远端入口。本轮沿用七星贩枣、杨志盘问、白胜挑酒、三人酒计及三担搬运，修正入场和停靠；回归另修正死亡接力的旧送担标记残留及重打时旧HUD离树后的延迟布局。最终同版玩法181项、全新八关Level组件207项、黄泥冈世界专项309项、全新经典296项及四批联合核验均通过；本轮相关专项完成，不是默认37用例完整世界验收或Steam发布。

## 行为

- 十五名押送者仍逐人从东侧山路走入，普通行走与身体分离继续生效。杨志保留原路；其余人经东侧空走廊分流，按每行由西到东停靠，目标间距从32增至64世界像素。逐人完成最后一段移动并停稳，三担实际抵达后才触发歇脚。已结束命令却被后来者挤离的人，会以正常移动归位；不重发仍在进行的行军命令。
- 刘唐应答杨志后，同一个白胜从原东侧入口挑酒走向松阴。只发一次关卡行走命令；实际到位且停稳1.5秒后落担，才出现酒桶、碗和酒计标记。
- 玩家可随时接管白胜。移动/攻击的指令序号、实际玩家命令的手动保护标记（包括停止/据守/巡逻）会取消自动行程，之后不会被定时器抢回。需要继续落担时，仍可右键原落担标记完成现场动作。
- 强夺立即取消自动落担，并停止仍归剧情所有的原行程；玩家自己接管的命令保留。白胜死亡或节点释放后，不以新角色代替原人。
- `bai_arrival_auto`、`bai_arrival_serial`、`bai_unload_t` 三字段纳入显式 Level 组件。途中世界恢复继续原移动与卸担进度；玩家已取消的状态不会因恢复重新开启。
- 携担人死亡后，退役该担上一轮送担动作：取消仍在办理的旧动作，从动作/标记集合移除并隐藏、释放旧控件。接力者的新送担标记能被同一出口点击选中；不把旧动作标成完成，也不制造完成事件，全局“遵循原点击”的认领规则保持。
- 三担同时携带时，退役列表中间的送担动作后，剩余旗标按现有动作顺序重新连续编号，随后新增接力标记不会与其他有效送担标记重号。动作ID、顺序和其他两担的携带关系不变。
- 真实重打后，旧HUD已离树时不再执行其延迟信息栏布局，避免访问空viewport；此处为共享HUD生命周期守卫，已补同版经典默认回归。

第三个 `order_move` 参数58是行军速度上限，不是停止距离。三担当前已取消建筑占格，不以“担子堵路”解释本次问题。原共用末段路线会穿过先到者停位，结合密排及全队同时到位条件存在收尾缺口；截图没有运行时追踪，不能声称确认它是每一次互挤的唯一原因。
