# 【更新】界面优化与战役体验修复

**中文**

各位好汉：

本次更新带来以下改进：

**底部指挥栏更清爽**  
未选中单位或建筑时，底部指挥栏会收成一条矮栏，只保留小地图和操作提示，战场视野更大。选中己方单位或建筑后，会重新展开完整的头像、属性与命令卡。

**第三章「三打祝家庄」体验修复**  
接应内应打开偏门时，成功提示不再重复堆叠；右侧键位说明在提示出现时会暂时隐藏，避免文字叠在一起看不清。

**其他**  
战役稳定性和界面细节继续打磨。战斗中途保存/续玩仍在开发中，本次尚未对玩家开放。

祝各位梁山聚义顺利！

---

**English**

**[Patch Notes] UI Polish & Campaign Fixes**

Hello heroes,

This update includes:

**Sleeker command bar**  
When nothing is selected, the bottom command bar collapses to a slim strip with the minimap and a hint, giving you a larger battlefield view. Selecting a unit or building expands the full portrait, stats, and command card again.

**Chapter 3 “Zhu Family Manor” polish**  
Opening the side gate via the inside contact no longer stacks duplicate success messages. The keybind help on the right hides while toasts are on screen so text stays readable.

Combat save/continue is still in development and not yet available to players.

Good luck on Mount Liang!
