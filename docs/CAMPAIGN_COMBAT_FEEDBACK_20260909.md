# 2026-09-09 战役战斗反馈：首批修复与待验证项

用户指出城门朝向歪、战役数值不合理、RTS 决策不足，以及集中兵力直接强攻即可过关。本批先修复可定位的城防交互与伤害结算问题，让攻城器械和破门战术产生可读的区别；这不等于已经完成全部战役的平衡和趣味性验收。

## 城防与攻城器械

- 祝家庄、大名府在指定守军城门和箭楼的定义上设置 `fortification_damage_mult = 0.25`，并以 `fortification_faction = Unit.FACTION_GUAN` 限定守军阵营。未设置城防的建筑、资源与己方箭楼不因此获得额外保护。
- `Unit.fortification_regular_damage_mult()` 是城防有效倍率的统一读取入口。普通武器与技能对上述设防建筑的伤害乘以 0.25；撞车、投石车的普通攻击豁免这一层城防倍率，其余护甲及既有战斗规则仍适用。
- 城防处理位于 `take_damage()`，在易伤、临时减伤、护盾和生命结算前执行。带技能身份的持续伤害和穿透技能仍受城防限制；明确的无来源内部移除保留例外，避免妨碍拆除、关卡清场等操作。
- 箭楼普通攻击改为使用受击目标的有效护甲结算。防御数值应当对箭楼攻击生效，避免面板护甲与实际战损脱节。
- 两关开战提示明确写出 25% 承伤及撞车、投石车的例外。内应、火号等既有战术路线继续保留，未把使用器械或完成演义条件改成胜利硬锁。

## 玩家能看见的规则

- 查看设防城门时，底部属性栏显示有效防御及武器/技能承伤百分比；查看设防箭楼时，仍显示有效攻击、防御和射程，并追加城防提示。
- 属性栏从实际倍率方法取值，不单独写死 25%。同一份建筑定义若因阵营变化失去城防，界面也不再显示该保护。
- 敌方查看沿用现有 `Battle._set_inspect()` 路径：清空己方选区和命令卡，显示敌方信息，不能给敌方下令。正常鼠标点选仍受视野限制。
- 中文源文字、繁体中文、英文、日文均已覆盖三个新增属性字符串和两个更新后的完整开战提示。语言切换通过现有 HUD 刷新路径更新属性。

## 快活林无准备站桩过关

本轮实际旧行为复现：0饮酒、0重拳躲避、0冲撞躲避、0反击窗口命中，持续普通攻击并施放Q/E/R，68.63游戏秒完成核心通关，终局32.32生命，最低24.62。原工具只要求站桩路线自然产生胜负，因此52项通过仍不能说明“硬干就能过”已解决。

当前短篇仅调整已有充分预警的重招命中代价：重拳32→56伤害、受击眩晕0.55→0.9秒；冲撞42→64伤害、命中减速持续0.55→0.9秒。重拳1.6秒/冲撞1.25秒预警、武松440生命、蒋门神800生命、双方基础普攻、QWER冷却与招式落空后的反击窗口不变。不设最低躲招次数或剧情胜利锁。

回归标准改为无准备、不主动躲招的Q/E/R站桩对照必须实际死亡失败；饮酒与不饮酒两条主动躲招、W实际换位、E趁破绽命中的路线仍须自然胜利。该标准只覆盖所述输入策略，不能声称专家或充分准备后的所有强攻组合都不可能成功。

## 本批验证与边界

- 静态检查已核对本轮五条字符串的三种翻译完整性、格式占位符、JSON 重复键，以及两关源码中的完整开战提示键；`git diff --check` 通过。
- 原生伤害71项、四语属性33项、祝家庄39项与大名府37项合同通过；两关各两条真实路线均自然通关。最终快活林53项及孟州门向24项通过：无准备站桩实际落败，饮酒/直接反击均胜利。四语属性8图与最终孟州2图逐张目检，完整数值、保留失败和来源边界见[QA](../qa/campaign_feedback_20260909/README.md)。
- 本批没有证明全部战役数值合理，也没有证明强攻路线与战术路线已达到目标难度；这需要实际操作证据，不能由脚本解析或自动通过战役替代。

## 孟州东门朝向

原 level7 使用 terrain2 的普通 `zhu_gate` 静物，贴图墙脚与官道的世界 X 轴平行；此路径没有消费 Unit 城门方向配置。本批为当前短篇入口增加独立孟州门静物路由，复用未改字节的 `daming_south_gate_default.png`，不生成、镜像或修改位图。两端石脚映射到屏幕 (-64,32)/(64,-32)，墙脚沿世界 Y 轴横跨官道，竖柱保持直立。阴影采用同一对脚点，官道由出生点延至 (2,19) 门槛。其他关卡的通用 zhu_gate 路由不变。

## 后续全战役数值与策略审计

1. 按关记录开局资源、采集效率、补兵成本和时间、人口、援军间隔、敌我有效伤害、主要目标耐久和行军距离；以当前定义与运行值对照，标出未进入结算的面板数值。
2. 用相同难度、相同成长状态比较集中强攻、兵种配合、经济扩张和剧情战术路线，记录耗时、伤亡、资源支出、操作频率及失败原因。
3. 优先修复不生效的护甲、距离、克制和目标选择，再调数值。避免只提高敌方生命和攻击，让战斗单纯变慢。
4. 逐关检验侦察、侧翼、资源点、补给线、前排保护器械及撤退是否存在实际收益；缺少可感知收益的设计仍列为未完成。
5. 在 1280×720 实际视野下核对城门、道路和通行口方向，并检查玩家能否从开战提示和选中信息理解关键规则；最后安排不熟悉关卡的玩家通关反馈。
