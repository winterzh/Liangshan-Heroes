# Steam 美术与镜头更新 · 2026-09-15

用户授权更新Steam，并要求公告展示部分原画。目标Windows App5088120 / Depot5088121 / default，更新前线上Build25316671。包含刽子手基础四向动作、董超/薛霸肖像与既有动作接入、32个环境目标、战船图标及镜头修复。

## 发布前发现与修复

首个候选包通用检查1128项通过，但包内美术专项发现酒幌校准失败：导出将PNG/TRES转为导入资源，原始文件SHA无法直接读取，导致新酒幌回退。现在源码模式继续核验原字节；导出模式核验同一来源路径、图集区域、画布边距、原生尺寸与解码RGBA像素SHA。像素校验按不可变导入纹理实例缓存，避免逐帧读回。原画字节和游戏规则未变。

修复后源码隔离检查321项通过，见`qa/steam_art_release_20260915/calibration_source/`。发行包专项及线上结果待续录，当前不能据此宣布Steam已上线。原始失败候选与记录保留，不覆盖历史收据。

公告计划使用酒肆、庄院/翠云楼图集、董超肖像三张原图，四语同步，标为素材展示；不宣称整体美术全部完成。
