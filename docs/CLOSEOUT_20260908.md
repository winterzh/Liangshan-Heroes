## 本轮 Steam 接口研究

研究只读取官方说明和固定版本上游源码，未构建原生桥、未更换 DLL、未安装编译依赖、未完成真实账号测试。项目固定 GodotSteam 4.22.1 / Steamworks 1.65，版本来源见 [provenance](../vendor/godotsteam/provenance.json)。

官方说明：

- [UserStatsStored_t / StoreStats](https://partner.steamgames.com/doc/api/ISteamUserStats#UserStatsStored_t) 的回调字段只有游戏ID和结果，没有应用的尝试或批次编号；IndicateAchievementProgress 也可触发该回调。不得把本地生成的 token 当成 Steam 返回的批次身份。
- [RequestUserStats](https://partner.steamgames.com/doc/api/ISteamUserStats#RequestUserStats) 返回 SteamAPICall_t 并异步读取服务器统计；缓存 getStatInt 读数本身不能证明服务器已确认某批写入。
- [StoreStats](https://partner.steamgames.com/doc/api/ISteamUserStats#StoreStats) 有速率限制；InvalidParam 表示部分统计因约束或过期被拒绝并回送更新值。结果8与本地持久标记之间的崩溃窗口仍需设计和验证。
- [离线模式](https://partner.steamgames.com/doc/features/achievements#offline_mode) 的多设备合并不能直接视为独立设备增量的因果相加或精确一次保证。

已核查的[固定标签源码](https://codeberg.org/godotsteam/godotsteam/raw/tag/v4.22.1-gde/godotsteam.cpp)：723975字节，SHA256 `da1a0676f846cbfe3d4da7da8e4ee5852fc9e97a07a430d4d38163eb06b677c2`。下载仅保留在忽略目录 `.godot/steam_api_research/`，不纳入提交，可按链接与哈希重取。

| 源码行 | 观察 | 后续意义 |
| --- | --- | --- |
| 6704–6709 | getUserStatInt 初始化为0，丢弃原生读取成功布尔值 | 脚本无法单靠返回值区分真实0与读取失败 |
| 6733–6738 | requestUserStats 返回 void，内部以 CCallResult 绑定实际调用句柄 | 原生层已有绑定，但脚本未获得原始句柄；需核实并发/取消语义 |
| 8879–8889、9912–9914 | user_stats_received 信号提供 game/result/user，stored 提供 game/result | 脚本信号没有原始读取句柄或写批次ID |
| 6941–6949 | isAPICallCompleted 无参数，读取成员 api_handle | 不能假定它查询 requestUserStats 的局部 api_call |

这些是标签源码观察，不是对已安装 DLL 的新增运行验证。内部 CCallResult 可能已提供所需的一部分关联，不能仅凭脚本没有句柄就判定整个读取接口不可用。尚未选定或批准引入新的原生依赖。
