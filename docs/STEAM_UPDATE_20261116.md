# Steam 八幕战役更新 · 2026-11-16

《水浒英雄传：八幕战役》Windows Build `26699320` 已在 Steam 正式分支上线。上一版为 `26260970`。客户端增量约 32.5 MB。

- 祝家庄完善守军破门反应、外围侦察、断援、正面强攻与孙立接应。
- 连环马改善协同下钩和护军行动，检查栏显示下钩条件，擒获韩滔后目标转入攻营。
- 江州和大名府改进追兵反馈、分路营救、登船撤离与待撤离伤员定位。
- 高俅三波攻势各有任务和倒计时，连船分开进港，座船带护航，刘唐可乘原船返港。
- 野猪林、黄泥冈和快活林改善救援、集合、推车接力、酒势与反击提示。
- 窄窗口下调整任务、消息和生产队列布局。

四语补丁说明已公开。Steam 客户端完成更新后启动到主菜单并正常退出。战役中途存档续玩的后续开发验收仍处于暂停状态。[Steam 公告](https://store.steampowered.com/news/app/5088120/view/708914425087656815) · [验收记录](../qa/steam_release_20261116/README.md)
