# 黄泥冈：先让人物按事情的先后到场

本批回应玩家实玩所见：抢纲者与押纲者同时挤成两团，酒已摆在路中间。修改对象为菜单第二幕「智取生辰纲」，实际入口是 `scripts/levels/level1_huangnigang_short.gd`，继承同目录 `level1_huangnigang.gd`。不按脚本编号误改江州。

原著第十六回中，七人和枣车已经在另一片松林歇脚；押队上冈停担，杨志看到窥望者后走去盘问；问过来历，白胜才唱歌挑酒出现。此次先实现这段可见的出场因果。原文来源：[维基文库第十六回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第016回)。同类玩法和玩家评论的研究另见[研究报告](CAMPAIGN_REDESIGN_RESEARCH_20260909.md)。

## 玩家现在会看到什么

| 阶段 | 场景与操作 |
| --- | --- |
| 商客已在松阴 | 七星分别站在七辆枣车旁，不再以密集战斗队形开场；照看枣车为可选动作。 |
| 押队上冈 | 镜头先看已在松阴的七星，押队从右侧陆续走入。杨志先进入，其后十一名军汉、两个虞候、老都管陆续入场并沿路行走，总共十五人。玩家仍可自由调度七星。 |
| 停担歇脚 | 押送者和三担实际到达后停步，有简短催行与歇凉对白；不通过瞬移把全队摆到冈顶。 |
| 杨志盘问 | 杨志从押队走近枣车，刘唐到现场应答。白胜和酒具此时尚未出现。 |
| 白胜挑酒 | 盘问完成，白胜从远处东侧入场，身上带着酒担。选中白胜，对落担旗标下令，让他实际走到松阴。 |
| 停步落担 | 现场交互完成才出现酒桶、酒瓢与酒计地点；随后进入现有酒计。 |

提前出现的酒来自 `campaign_environment.gd` 中一个无条件的 `market_stall(...,"wine")`，与任务后来生成的酒桶不是同一个物件。本批移除黄泥冈这项固定景物，快活林的酒肆等场景保持各自配置。已有商客、枣车、担子与携酒素材继续复用。

## 自由行动与边界

玩家可以在押队途中主动强夺。尚未到场者继续以原十五人名册入场，不无限补兵，也不把已倒下的人重新生成。白胜在强夺分支可从远路加入；若原白胜已经死亡或节点释放，后续回调不会再生成替代者。任一幸存同伴仍能接力搬担。

落担回调同时检查阶段、商客盘问事件、白胜本人、现场距离和实际动作完成状态。提前调用、只到地点、重复调用均不能凭空摆酒或重复生成。重打清除本关后段场景与事件，重新开始入场。

新增的唯一关卡字段 `convoy_entry_t` 已纳入现有 Level 组件的显式浮点白名单；十五人名册继续使用原 `convoy` 引用列表。上冈推进统一放在基类，标准版和当前短篇入口共用，避免旧版仍按已不可达的旧终点等待。阶段枚举、菜单顺序和章节ID不变。此内部组件变动不代表开放战斗中保存/继续。

新出现的24条中文文本补齐繁中、英文和日文；旧译文不改。
