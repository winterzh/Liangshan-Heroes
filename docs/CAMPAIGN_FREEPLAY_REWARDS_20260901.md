# 八关自由通关与“演义印”规则

更新日期：2026-09-01。

本轮追加了八关真实指令路径复核：测试不点击任务按钮，而是经过游戏实际使用的选人、右键移动和右键集火入口。公共交互22/22、前四关47/47、后四关69/69通过；前四关实际发出19次移动、4次攻击，后四关发出8次移动、10次攻击且任务按钮调用0次。最终串行回归21/21通过，运行期文件哈希前后不变，无脚本或解析错误；15/21作业保留既有ObjectDB退出警告。详细指令契约、证据与边界见 [CAMPAIGN_MANUAL_ORDERS_20260901.md](CAMPAIGN_MANUAL_ORDERS_20260901.md)。

本轮把战役结算拆成两层：玩家完成每关的**核心目标**即可基础通关；按原著完成本关全部“演义目标”，才收录该关的**演义印**。玩家可以提前现身、强攻、跳过准备或改用自己的编队，只要没有造成核心目标已经不可能完成，关卡就继续。偏离原著会立刻说明失去的是哪一项演义目标，不再把“没有照按钮顺序做”一律判成战役失败。

演义印是章节完成记录，不增加人物属性、资源、兵力或永久能力。每关记录基础通关、单局最佳演义目标数和是否曾在**同一局**完成全部目标；系统不会把多次重玩的零散目标合并成一次满完成。菜单卡片显示“基础通关”“演义复现 n/m”或“演义印已收录”，战报分开列出核心结果与演义结果。已经收录的演义印会保留，玩家仍可自由重打。

## 公共规则

- 八关从开始即可选择，原著顺序仍是野猪林、智取生辰纲、醉打蒋门神、江州劫法场、三打祝家庄、大破连环马、智取大名府、三败高太尉。旧的 `LEVEL=N → levelN` 启动含义保持不变。
- 任务按钮只是替玩家选择合适人物并派往现场。玩家手动办理任务时，必须以一次真实命令明确点击任务目标，并让人物实际进入办理范围；同组共享的一次性 token 被一个动作消费后，全组清除，不能一键串办后续动作。
- 点击半径与物理办理半径分开：人物已经靠近不等于点击任意位置都能办事；多个标记同时可用时按全局离点击点最近者认领。江州中点测试中，人物虽同时位于救宋江、救戴宗的办理范围，点击两标记中点仍不会救出任何一人。
- 玩家发出有效的移动、攻击、技能、物品、驻扎、维修、续建、新建或陷阱命令，会取消任务按钮的自动路线而不伪造任务完成；无效操作不取消。完整规则见自由指令复核文档。
- 偏离原著只取消相关演义目标。人物全灭、必须营救者死亡、目标物被毁、忠义堂失守或已经没有可用兵力等情况，才按核心目标失败。
- 昏迷、制服、被擒、撤离与登船均有独立剧情结果。不能用击杀代替制服或生擒，也不能靠“曾经救出”掩盖人物后来死亡。
- 祝家庄、连环马和终章仍按章节时间重新部署。转场只继承剧情标志，不把跨日战斗拼成一场连续冲锋。

## 原著依据与改编边界

- 野猪林依据[第八回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第008回)：鲁智深暗随、拦棍，林冲求情保住解差；照料与同出林是把后续护送压成可操作目标。
- 智取生辰纲依据[第十六回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第016回)：七星扮枣客，白胜另卖酒，以试酒、瓢与蒙汗药完成智取；强夺是允许玩家偏离原著的游戏分支。
- 醉打蒋门神依据[第二十九回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第029回)：沿路饮酒、到店佯醉、玉环步与鸳鸯脚、逼蒋门神应下条件；招式读条与反击窗口是玩法改编。
- 江州劫法场依据[第四十回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第040回)：李逵先扑法场，众人救宋江、戴宗后奔白龙庙，与水军相会；提前起事和直奔码头是自由分支。
- 三打祝家庄综合[第四十八回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第048回)与[第五十回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第050回)：盘陀路认路、生擒扈三娘、孙立内应与开门夹击跨日发生，游戏以三幕重部署压缩呈现。
- 大破连环马依据[第五十七回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第057回)：盗甲赚徐宁、钩镰枪训练、草林伏兵、韩滔被擒与呼延灼败走青州；十二骑是对大规模甲马的玩法压缩。
- 智取大名府依据[第六十六回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第066回)：元宵混入、翠云楼火号、牢中接应与各路响应；当前地图集中在南门，没有复刻全城多门兵力。
- 三败高太尉依据[第七十九回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第079回)与[第八十回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第080回)。第七十九回写吴用令刘唐受计掌管水路、公孙胜祭风、众水军小船从港汊钻入相连官船队举火。游戏把大批火船压缩成一条由刘唐实际登乘和操纵的代表火船、两条接应船；这是规模压缩，不宣称原文只有刘唐一人或只有一条火船。第八十回写张顺凿漏高俅座船、把高俅拖下水，再由小船接起押回。

这些目标是忠于人物结果和事件因果的游戏改编，不是逐句复演。规模、路程、时间、城门数量和参战兵数都经过压缩；自由打法也不应反过来宣称是小说原情节。
