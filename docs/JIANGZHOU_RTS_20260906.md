# 江州劫法场：有限补给军队救援

2026-09-06，接续 `374b2ec`。菜单 `level2` 使用 `scripts/levels/level2_jiangzhou_rts.gd`，兼容章节ID与顺序，演义合同版本2。旧 `level2_jiangzhou.gd` 保留地图和装饰来源，不再是菜单流程。当前四个大型经营战役之外，江州承担紧急救援调剂；三个短篇与真人趣味验收仍待完成。

## 玩家能做的选择

- 西街、江边两座接应营共用190金120木，初始人口22/36。按驻守原价、人口和时间招募刀、枪、弓、骑；不部署工人或采集节点，也没有升代、研究等待流程。
- 西街和南巷各一处补给棚，清开周围官军后手动领取100金60木，各限一次。可以集中钱粮赶到法场，也可分兵取粮、补充后队；共享战斗收益仍会入账。
- 从开战起150秒内击败两名刽子手即可停止行刑，随后分别手动救人。无需清图、拆完建筑或完成可选路线才能救下二人。
- 法场箭台覆盖解救区；南巷有骑弓、第二座箭台和江边截兵。护卫开路与伤员撤离分开编队，可以中途换路。获救宋江、戴宗不能攻击、施法或提供英雄光环；保留解缚前生命及脱战恢复倒计时，随后沿用共享恢复规则。
- 二人分别到码头旗标办理登船；附近有追兵时可清敌后重试，人物定位按钮也恢复可用。护卫在岸边断后，让出登船通道。二人安全上船后出现明确的“开船通关”，玩家可以立即离开，也可以等全员撤回。

两座营地、所有军队、战损和资源跨阶段保留，不用换场重部署。兵种/英雄的生命、攻击、费用、训练时间及技能沿用共享定义；伤员状态和紧急接应营的研究限制仅在本关生效。

## 敌军反应与有限来源

开局守军、两名刽子手、蔡九、两座箭台和六人北面预备队均为实际单位。起事前守军等候；初始救援队和新补出的兵保持避战，玩家发起进攻后守军与救援队恢复正常战斗姿态。箭台等待期间暂停自身物理攻击，防止建筑忽略移动单位的避战开关而偷打燕顺。

东街巡防营在起事32秒后开始补军，使用自己160金100木及共享战斗收益支付对应刀兵/弓兵费用，并等待正常训练间隔，总数最多8人。拆营永久停止该来源，已出场兵不会消失。首名囚徒获救后，北面原有六人得到20秒行动预警；时间到后追向获救者，不在背后凭空重刷一组。

两名伤员中任何一人遇害即失败。具名救援好汉阵亡只影响全员撤回演义目标，其他人和普通部队仍可接手核心营救。任一接应营损失不直接判负；有限资源用尽后也不会自动生成免费兵。尚有囚徒未救时，若无人可办理且没有在训队列或可支付的替补，明确提示救援失败；真实付费替补仍在训练则允许继续。

## 四项演义目标

| 目标 | 实际条件 |
|---|---|
| 李逵排头 | 李逵完成西街就位、燕顺完成南巷接应且仍在接应区，随后由李逵发动；其他人提前进攻仍能核心通关 |
| 分别解救 | 两个独立的救人命令，不能用模糊中点或旧移动凭证一次救两人 |
