## 素材与接入

生产资源为 `assets/characters/mounted_portraits_20260926/sun_li.png` 与 `hu_sanniang.png`。二者由内置 `image_gen` 以原头像为编辑目标、当前模型为服装依据生成，使用现有陆谦头像仅作画法与纸纹参考，未借用其五官。原生 PNG 逐字节复制，未使用 CLI 或本地图片后处理。

`tools/contracts/mounted_portraits_20260926/` 保存完整提示词、逐张参考、输出 SHA-256、尺寸与生成标识；来源表同时记录两人的五状态四向 `.tres` 及其直接引用的纹理文件。旧头像保留为来源链。

只更改 `Art.STANDALONE_PORTRAITS` 的两条路径。图鉴、战斗左下角与英雄栏沿用共同的 UI 头像入口。模型、动作、骑乘和剧情变体归属不变。
