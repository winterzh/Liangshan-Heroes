# 战役物件图标与场景来源 · 2026-09-27

## 修订

快活林的可选店招在世界中采用关卡专用木牌，旧 HUD 只按 `signboard/heyang_tavern` 查图，显示成酒楼。新增 `Unit.ui_portrait_texture()`，让已有场景实例的建筑查询自己的有效关卡、物件路由和状态；左下角面板、选中单位小图标、有实例的剧情头像及英雄栏使用此入口。

- 快活林店招显示现有木牌素材；四处酒望遵守与世界绘制相同的透明图集回退。
- 第五幕忠义堂可使用实际的关卡建筑素材。遭遇战保持其 `skirmish` 作用域，不能误加载第五幕专用素材。
- 人物继续调用 `Art.ui_portrait_texture(key, art_variant)`，保留标准画像、不同脸型、剧情变体的身份校验。
- 被缚人物、资源、防御塔、由场景层绘制的原生寨门继续各自的绘制分支；即使附带物件路由元数据也不借用普通建筑图标。
- 图鉴和建造/训练等无具体场景实例的列表仍通过 `Art` 查询基础定义。未将战役专用路由注册为全局素材。

## 与世界绘制共用校验

`Unit._campaign_environment_texture(update_metadata := true)` 保留原世界行为。UI 传入 `false`，读取同一关卡范围、有效状态、来源校准和文字表面校验，但不删除或写入脚点、文字矩形等场景元数据。缺失、越界、无效状态或不匹配校准均回到原物件图标。

没有重绘或复制生产图片，没有裁切校准边界；原生透明边缘、图集区域与留白保持原样。场景“河阳风月”“忠义堂”等动态文字仍由世界绘制器叠加；图标呈现原始物件图，物件名称在 HUD 文字区显示。

## 验证范围

`tools/scoped_object_icons_qa.gd` 与 `tools/run_scoped_object_icons_qa.py` 使用上一批 187 定义/45 变体的完整路由表验证全局素材不变。新隔离运行检查无关卡上下文时的逐定义回退、命名人物身份、UI 元数据无副作用、错误关卡/状态/路由/文字表面的回退，并查看当前第七幕四酒望/店招/武松、第五幕忠义堂及遭遇战聚义厅的真实界面。

验证和截图见 [QA](../qa/scoped_object_icons_20260927/README.md)。这是战役物件取图一致性修订，不代表所有人物四向、环境、技能特效或整套 UI 已验收。
