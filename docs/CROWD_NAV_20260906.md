## 行为与实现

拥挤分离会反复尝试几像素的位移。原求解器每次调用完整线段导航，重新检查起点边界和所在格。本版在一次同步求解开始时读取每个单位所在格是否开放；目标仍位于该开放格内且坐标有限时，可以直接接受位移。跨格、封闭格、边界外或导航未准备好的情况仍经过原线段方法；跨格成功后更新本次求解内的格子范围。

本次求解内没有回调或地形改写，实际 Node 位置仍到结尾才写回。所有格子记录都是局部变量，下次求解重新读取，所以封格/解封、直接修改陆地或水面 AStar、同尺寸重新 bake 都能立即反映。没有持久导航缓存。Rect2 右/下边界排除，目标先检查有限性，避免非有限位移落入快捷分支。

单位顺序、重复单位/桶成员、实例 ID 配对、移动与静止权重、半径、淘金穿行、陆水分组及逐对更新顺序保持。小于 64、稀疏队列和大于 320 的分阶段路径仍由 Battle 原分派处理，未改变其规则。
