## 1. 一关合格的 RTS 战役应该让玩家做什么

2026-09-06 补充：木墙修正及造船底层完成后，高俅已接入同一营寨的持续水陆经营、有限付费补充、可选火攻与实际押俘回堂，并跑通经营强攻和完整演义两条自动路线。见 [高俅实现与边界](GAO_RTS_20260906.md)；真人趣味、教程与火攻容错还需试玩，不以自动通关代替体验验收。

核心循环是：**侦察局势 → 分配钱粮与兵力 → 建设和整军 → 争夺地图目标 → 敌人作出反应 → 补兵、调整、推进战线。** 故事决定为何出兵、争什么、怎样收场；主要操作应不断改变战局。

| 标准 | 本项目中的具体表现 | 需要警惕的体验 |
| --- | --- | --- |
| 经营有取舍 | 同一笔金木可以补兵、增工人、修塔或攒器械；前线与后方同时有事可做 | 固定送兵让资源无意义，或只有开场等钱 |
| 地图值得争 | 营地、资源区、通路、射界和敌方兵源价值不同；侦察会改变进攻安排 | 大地图仅增加赶路，支线只加结算分 |
| 兵种有用途 | 刀兵顶线、枪兵抗骑、弓手输出、骑兵绕后、撞车拆门；英雄负责带队和关键技能 | 只造一种兵，或英雄包办所有工作 |
| 解法可选择 | 正面攻坚与迂回断援都能完成核心目标，途中可以撤退补兵换招 | 必须按指定人物、坐标、顺序办理 |
| 主题鲜明 | 内外夹攻、破骑兵冲锋、水陆配合，改变正常经营和用兵方式 | 八次守同样波次，或每关另教一套无关操作 |
| 压力可应对 | 来袭有侦察/预警；拆营、断粮、控路会削弱后续威胁 | 无来源刷兵、无提示必败计时、单纯加血 |
| 有变化和收束 | 落脚、抢关键区域、形成优势、完成主目标；优势足够后尽快结束 | 胜局已定仍找最后一个藏兵，阶段重置抹掉努力 |
| 失败能学到东西 | 目标简明，生产和人口反馈一致；失利知道原因，有合理重试入口 | 剧情抢控制、拥挤难选、次要失误要重打全关 |

这是本项目的设计与验收标准，不是所有 RTS 战役必须建基地的定义。野猪林、黄泥冈、快活林可以保留短篇剧情玩法；大多数游玩时间应由经营与战场决策承载，实际比例须试玩后测量。

## 5. 首个样板：三打祝家庄

目标：真正经历“驻扎经营 → 争外围 → 攻坚”，能说出至少两次由自己决定并影响结果的战略选择。先用现有素材做完整可玩的一关，重检地图容量、建造位置与通路。

### 玩家会经历什么

1. **落脚与侦察。** 小型前营、工人、一支可出门的军队和本章英雄；后方能采集、造民居和补兵。可侦察较近的资源区，或先探能削弱来袭的外围兵源，无需等大批建筑完成才有事做。
2. **第一次进攻探清格局。** 正门坚固，侦察可发现侧路和援军路线。可以试探后撤、先断援或攒器械强攻；不要求第一次必须输光一队，打得好应保留战果。
3. **站稳外围、应对反扑。** 资源区能多养一支队伍，但须保护工人与通路；摧毁外营停止该处出兵，若允许重建则有真实资源/时间成本。玩家决定留兵防家、护工还是攒器械。
4. **内应与总攻。** 内应提供侧门与救囚机会。玩家可正面撞车推进，也可佯攻后转侧门；内应受阻仍可正面核心通关。军队控制战线，英雄技能制造突破。
5. **结算成果。** 及时显示核心目标、必须存活人物与失败条件；完成最终核心目标即结算，不强制全图扫尾。演义目标保留为额外挑战。

“三打”建议保留为侦察受阻、外围争夺、总攻的叙事结构；营地、已探区域、已夺节点和普通军队损失默认延续。具体阶段衔接待实现，不能继续靠重部署无条件清空军队/建筑再塞预设兵。原著必须出现的被俘/救援事件需标明对象，与普通可生产部队分开。

### 最小实现范围

- 一个前营、一个可争资源区、一个有来源的外围敌营、庄门与侧路。先用单个敌方经济账户；多势力外交和多个独立敌方经济暂不纳入。
- 接经济钩子、采集卸货、人口、补兵、作坊、修理、章节英雄名单。初始250金/150木/20人口仅为驻守比较基线，须结合开局单位核算；样板从时代3起步，让器械能生产，暂不同时验证升代曲线。
- 开放必要的刀枪弓马与器械组合，控制英雄数量与操作量；名单符合章节，不直接开放108将挤掉普通军队。
- 提取1v1 AI 必要逻辑并移除固定坐标；剧情额外援军单列有限预算、来源和预警。外营被拆后不能继续在原地免费出兵。
- 重写祝家庄阶段生命周期与胜败判定。营地与关键状态不被公共 begin 清空；仅在双人同时办理确有需求时扩展 `CampaignMission`。
- 复用迷雾、编队、集结点、快捷键和命令卡。提示解释目标与威胁；剧情不代选、代走、代放技能或强制撤军。
- 中段重试/存档需先核对能力再接入，不能将章节存档等同完整战斗快照；旧自动测试不等于覆盖新经营场景。

### 验证与验收

1. 真实命令完成采集、建造、生产、补人口、修理、进攻；缺钱/满人口/建筑被毁时行为一致，初始人口和科技名单匹配。
2. 至少正面器械攻坚、夺外围断援后侧攻两条路线能通关；保守留家与积极扩张都有代价，不要求唯一英雄或指令顺序。
3. 骚扰工人、拆兵营实际改变补兵；普通战斗失利后有恢复机会；资源耗尽或核心不可完成时不无限空转。
4. 内应受阻、非关键英雄阵亡、救囚、换阶段、重开/退出无软锁，不重复领援军/结算/复制英雄，不丢已建营地。
5. 回归驻守、AI对战、原八关入口和模式切换，确认共享定义未污染；关注复活、人口、塔、器械、船只。解析和主菜单启动不能代替场内验证。
6. 真实战斗验证路线，不冻结敌军或写胜利标志证明平衡；测拥挤寻路、操作反馈与长时性能，单位增加后以实测设预算。
7. 找3—5位首次玩家，记录目标理解、主动选择、无事可做的段落、失败原因、时长、普通兵补充、是否愿意换打法重玩；收集反馈再调参，不把自动断言全绿写成“好玩已通过”。
