# 帝国时代多版本深挖：战役与经营对水浒的启示

日期：2026-09-14。只研究同类型（基地/资源/部队/战役）。样本：Steam 简中评测（AoE II DE / III DE / IV），对照神话时代既有结论。未改源码。

约束：不魔改原著；借鉴结构，不照搬卡牌/主城等与水浒底座冲突的系统。

## 2. 二代：战役教科书（最贴近水浒）

### 2.1 战役类型（应直接抄进八关标签）

| 类型 | 玩家做什么 | 水浒关 |
| --- | --- | --- |
| Build & Destroy | 从零建到能推平 | 祝家庄、连环马、大名府、高俅 |
| Defend | 守到援军/时间 | 经典 30 波；高俅中段 |
| Fixed Force | 无基地，给兵和目标 | 野猪林、黄泥冈、快活林 |
| Escort / 特殊胜利 | 护送、占点、剧情触发 | 江州救人、黄泥冈押担 |

好评原文：「超过 200 小时的战役内容」「贞德到成吉思汗」「三国 DLC 赤壁火攻」——**体量 + 历史可读性**。

### 2.2 文明差异 = 战术换脑，不是换皮

长弓射程、蒙古骑射、诸葛弩——同一套操作，**编队配方不同**。  
差评里也有「部分文明特色同质化」——后期平衡一刀切会毁掉差异。

**水浒**：章节差异应改变「怎么打」：连环马逼反骑、高俅逼水陆、大名府逼内外线。不要做成「八个关都是爆刀兵」。

### 2.3 二代差评对我们的警告

| 差评 | 水浒风险 |
| --- | --- |
| 单机反作弊误伤 | 任何「防作弊」不得妨碍单机/战役存档调试 |
| 战役语音文本错位、BUG 几年不修 | 四语 + 图鉴文案要进验收，不能只验 SHA |
| 崩溃进不去 | 帧/崩溃是发行门槛，不是「以后再优化」 |
| 学习曲线陡 | 野猪林必须短且教会；经营关第一次采矿不能靠玩家猜 |

## 3. 三代：创新过头的反面教材

### 3.1 做对了什么（好评）

- **主城船运卡**：局外准备 → 局内一波支援，「像拆礼物」。  
- **探险家英雄**：有技能、有存在感。  
- **节奏更快**：对局不像二代拖。  
- **「战争艺术」教程**：把采集/克制拆成小挑战。  
- **内容体量大**：20+ 文明，历史战役追加。

### 3.2 做砸了什么（差评）

| 问题 | 原话/现象 | 对水浒 |
| --- | --- | --- |
| 学习成本过高 | 20 文明机制全不同，萌新无法举一反三 | 八关共享金木/兵营/人口；差异在**编队与目标**，不在每关一套新系统 |
| 平衡成蜘蛛网 | 兵种克制网状，永远补不平 | 克制关系保持**可读三角**（刀/枪/弓/马/器械） |
| 寻路高血压 | 单位抽搐、绕远 | 寻路/自动索敌是差评第一名交集 |
| 过度创新丢老玩家 | 「生不逢时」「不受系列玩家待见」 | 水浒身份 = **好汉 + 经营战役 + 原著**；不要为了「像某作」加卡牌/主城 |
| 免费版阉割伤口碑 | 转免只给轮换文明 | 商店描述与实际开放内容一致 |

**三代教训一句话**：系统可以深，但**每关玩家只需要想一件事**；准备层（卡组）若存在，战役里应可默认、可简化，不能变成第二份作业。

## 4. 四代：回归与新坑

### 4.1 好评

- 「战役质量挺高的」「先玩战役了解基本玩法」。  
- 文明差异被夸「比二代同质化强」。  
- PVE 合作呼声极高：「类似星际 2 合作的 PVE 模式，对不敢打天梯又喜欢 RTS 的玩家很重要」。  
- 有人只打人机、狂造箭塔也能乐——**人机爽感是合法需求**。

### 4.2 差评（题材与稳定性）

| 问题 | 现象 | 水浒 |
| --- | --- | --- |
| 岳飞 DLC 玩金朝 | 「岳飞传奇没有岳飞」；玩家嘲讽「选金朝对面人人都是岳飞」 | **名著关必须让玩家扮演/陪伴梁山一方**；不能为「平衡视角」让玩家全程操作官军灭梁山 |
| 崩溃、掉线不能重连 | 差评高权重 | 阶段重试 + 稳定 |
| 匹配/组排环境 | 「野排队友…」 | 我们主打单机战役，不把体验绑在联机上 |
| DLC 圈钱感 | 战斗群付费、内容切碎 | 公告不夸大；一次把「八关+30波」验收完整再谈扩展 |

**四代题材教训**：IP 游戏里，「谁是主角」比「历史是否全面」更先被玩家审判。

## 5. 神话时代对照（同系列旁支）

- 主神/次神选择 → 同一套 RTS 多种流派。  
- 战役 60+ 关、强趣味弱竞技、「养老 PVE」。  
- 差评：把特色削成换皮、闪退、寻路。

**水浒**：好汉技能池 =「次神选择」的位面——宋江补员、林冲突破、李逵冲杀、扈三娘机动。  
**禁止**：为了平衡把所有人改成同一套平砍。

## 6. 系列演进 → 水浒设计原则

```text
帝国演进简图

II  战役类型全 + 文明差异清晰 + 历史可读
      ↓ 创新
III 船运卡 + 英雄探险家 + 更快节奏
      但：机制爆炸、寻路、老玩家流失
      ↓ 回归
IV 现代战役包装 + 更强文明差异
      但：崩溃、题材 DLC 翻车、联机环境
```

### 6.1 必须学的

1. **战役是产品**，不是教程附赠——PVE 体量与质量决定口碑。  
2. **关卡类型标签化**（B&D / Defend / Fixed Force / Escort）。  
3. **文明/章节差异改变编队配方**，不是数值皮肤。  
4. **教程关短且真教会**（野猪林）。  
5. **人机/单机友好**：可暂停、可重开、不反作弊误伤。  
6. **名著 IP：玩家必须站在梁山叙事主轴上**。

### 6.2 必须避的

1. 每关一套新系统（三代教训）。  
2. 平衡削平特色（神话/二代后期教训）。  
3. 寻路与崩溃（全系列差评交集）。  
4. DLC/宣传与内容错位（四代岳飞、二代语音错位）。  
5. 联机绑架单机（四代匹配差评）。

## 7. 对八关的帝国式标注（建议写进菜单）

| 关 | 类型标签 | 玩家「新学会」的一件事 | 差异如何改变编队 |
| --- | --- | --- | --- |
| 野猪林 | Fixed Force 教学 | 跟随、出手时机、护人 | 无基地，纯小队 |
| 黄泥冈 | Fixed Force 劫运 | 并行办理、护退 | 失手可强夺 |
| 江州 | 有限补给 Escort | 分兵、控路、撤离 | 码头兵额二选一 |
| 祝家庄 | Build & Destroy | 断援 vs 正面 | 内应开门是另一条路 |
| 连环马 | B&D + 兵种课 | 反骑编队 | 钩镰/拒马必学 |
| 快活林 | Hero Duel | 读招、酒力取舍 | 酒序改变架势节奏 |
| 高俅 | Defend→Counter | 水陆两线 | 火船 vs 岸军资源分配 |
| 大名府 | B&D + 双线 | 城外经济 + 城内行动 | 注意力与补给切分 |

30 波 = 独立 **Defend 模式**，与战役并列，不互相抢「唯一正统」。

## 8. 五句验收（帝国版加强）

1. 本关类型标签是什么？和上一关是否轮换？  
2. 本关「新学会」的一件事，下一关是否用得上？  
3. 章节差异是否改变了**编队配方**，而不只是敌军血量？  
4. 玩家是否始终站在**梁山叙事主轴**上？  
5. 寻路、崩溃、存档、文案有没有在浪费时间？
