## 2. 精华十二条

### 战役结构

1. **一关只教一件事**（星际）：新兵、新技能、新威胁，下一关立刻综合用。  
2. **类型必须轮换**（星际/帝国）：建造关 ↔ 固定兵力 ↔ 防守 ↔ 英雄关；连续三关同节奏会枯燥。  
3. **胜利条件一句话说得清**（红警）：摧毁 / 护送 / 生存 X / 占点。  
4. **可选目标给重玩，不挡主线**（星际/帝国）。  
5. **战役有收束**（全战三国差评反面）：半成品比难玩更伤。

### 英雄与部队

6. **英雄是 RTS 的身份，不是皮肤**（魔兽）：技能、走位、阵亡代价；短篇关可以几乎无基地。  
7. **兵种要有不可替代用途**（帝国/CoH）：枪反骑、弓射界、刀顶线、马绕后、器械破墙。  
8. **位置 > 人口**（CoH）：一队放对地方能换多队；不是 F2A 堆数字。

### 经营与波次

9. **失败可归因到十分钟前**（Northgard）：没断援、没护工、器械太晚——不是「兵不够」。  
10. **推进与防守有钟摆**（亿万僵尸）：推慢经济死，推快被反扑；出门要有代价能回来。  
11. **禁止不可逆软锁**（亿万僵尸战役差评）：科技/解锁可预览、可重置；不要点错就废档。

### 操作底线

12. **寻路、误触、崩溃、存档**是差评交集（C&C/CoH/Iron Harvest/Northgard）：  
    高惩罚键位可改；自动索敌不拆己方关键目标；阶段重试；帧与稳定达标。

## 3. 对照水浒八关（现结构已对，要验「轮换」）

| 顺序 | 关 | 应声明的类型 | 应避免 |

## 4. 验收时问这五句

1. 本关引入的**唯一新东西**是什么？  
2. 和上一关类型是否**轮换**了？  
3. 输了能指出**自己哪个决策**错了？  
4. 有没有**第二条实质不同**的解法？  
5. 寻路/键位/存档/崩溃有没有在**浪费时间**？
