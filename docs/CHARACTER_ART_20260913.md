# 孙立、扈三娘四向基础动作

2026-09-13。用户将近期工作优先级调整为美术，允许多会话并行。本批为孙立、扈三娘补齐通用战斗的东南、西南、东北、西北四向站立、行走、攻击、受击和死亡动作。制作、来源与轮廓审查并行，接入和Godot验证串行。

导入基础层不含mipmap和引擎开销，不作为FPS结论。每向idle/walk/attack/hurt/death为1/4/5/1/4帧；重复帧只安排时序，不算新画稿。攻击采用预备两帧、命中两帧、回位一帧，既有伤害触发点落在命中姿态。

孙立复用6张经哈希和逐姿态审查的旧RGBA，新增5张。东南补独立马步；西南原图的攻击/受击会串入邻格马蹄，改用四动作独立排距图。扈三娘9张均为本批新RGBA；东南、西南补独立马步，并将西南两格、东北四格、西北两格从拥挤原图拆出。退回区域在manifest中明确记录，前景按alpha>15由选中与退回区域各覆盖一次，不用放宽裁框检查掩盖串格。

两人都是低帧数基础动作。孙立西南/西北两步的前腿变化较弱；扈三娘部分方向为伸腿支撑与收腿的两相变化，均不宣称完整高帧跑马或连续转身。绘制尺度、透明留边和地面锚点通过元数据调整，物理位置、选择圈和碰撞不随美术摆位改变。

## 设定与接入边界

扈三娘采用原著明确的甲衬红纱、金钗与日月双刀；深色鬃毛对应青鬃描述，棕色马体是沿用的游戏设计，不冒称原文规定。参见[一百二十回本第四十八回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第048回)。孙立保留淡黄面色、胡须、骑乘和虎眼竹节钢鞭；黑金甲、褐袍和黑马沿用既有设计。参见[第四十九回](https://zh.wikisource.org/zh-hant/水滸傳_(120回本)/第049回)。

原生图片由内置image_gen生成或编辑，PNG按原字节入库，提示词和采用参考链完整保留。本地没有抠图、镜像、补画或重新编码PNG。Godot标准导入缩放并启用mipmap，AtlasTexture指定采样区域、透明留边、尺度和脚锚。

`Art`已有通用四向TRES路由，无须另加角色分支。唯一游戏代码改动是`Unit.AUTHORED_DIRECTION4_ATTACK_KEYS`增加两名角色，避免已画入挥击的动作再叠整图旋转和剑弧。角色属性、技能、剧情、地图、经济与碰撞均未调整。孙立分身沿用本人素材；扈三娘被擒保持活体、敌方与原实体，使用既有非死亡休止回退，不借用死亡图或自动招募。

## 验证状态

两角色标准来源检查分别380项、259项通过，40个TRES由manifest重建比对无差异。原生复查发现扈三娘SW行走的半像素尺寸被Texture2D分别取整后不再方形，现只增加透明边带并使用整数尺寸，构建器新增拒绝守卫；原图可见前景不变。孙立各姿态的绘制倍率统一除去原1.35放大，保留不同画布相对补偿，使头部避开既有血条。孙立隔离无画面运行626项通过，覆盖真实四向移动/命中、受击/死亡、R分身与实际到位接应、中断和重新下令。首次脚本类型推断错误、后续JSON数字数组比较及纹理浮点精度断言错误均作为失败批保留，修正只发生在QA脚本。

最终同版图形批20260913_180852_fc6b5bef已通过：孙立651项、扈三娘609项，共1260项；共享路由8项、全库盘点通过。52张实机PNG全部核验SHA；人工复查两人全部六张姿态总览及代表移动、战斗与生擒画面，准确范围见[本轮QA](../qa/character_art_20260913/README.md)。本批不代表全库美术完成，也不替代完整30波、真人手感、长期性能或Steam发行验收。
