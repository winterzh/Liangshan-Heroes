# RTS 玩法调研：好评差评与水浒对照

日期：2026-09-14。本轮只做设计研究，未改游戏源码、数值、章节顺序或 Steam 包。约束沿用「不要魔改，能行就行，不行就算了」：借鉴可迁移的 RTS/RTT 玩法原则，不扩写原著没有的军事行动或经营系统。

**更正（同日）**：初稿曾误将 *Slay the Spire*（卡牌肉鸽）与 *Hunt: Showdown*（撤离 FPS）写入 RTS 参考表，并因 App ID 记错（646570 实为尖塔）未采到 *They Are Billions*。本版已删去非 RTS 条目，补采 *They Are Billions*（644930）、*Company of Heroes 3*（1677280）、*Iron Harvest*（826630）。**杀戮尖塔不是 RTS。**

调研方式：Steam `appreviews` API，简中为主、辅以英语；对照本项目 `CAMPAIGN_FUN_REWORK_20260905.md`、`KUAIHUOLIN_SHORT_20260906.md`。样本用于主题提炼，不是科学抽样；引用均为玩家原话短摘。

本店公开评价（App 5088120，截至抓取时 1 条）：「想法不错，题材不错，但距离一款合格的RTS，需要补的课太多。」（20 分钟）。

## 2. 好评：为什么好玩

### 2.1 波次与扩张的压力要可读、可准备

*They Are Billions* 好评主因是生存压力与「再来一把」：「前面杀僵尸杀的让人兴奋」；高手复盘也是「推得快惊动大块头等于暴毙……要把握好平衡」——扩张节奏本身是决策，不是堆数值。Northgard 同构：「你不一定缺地，你可能只是管不过来」。

**对水浒 30 波**：每波/精英来源、方向、威胁类型要可侦察或预警；扩营 vs 补兵 vs 修塔的代价要在下一波立刻兑现，而不是后期突然翻桌。

### 2.2 经营循环清晰，且兵种有用途

AoE II 好评：「上手难度很低，更加注重策略性」+「极为庞大的战役体量」；文明「专属战术体系」。TAB：「有趣的兵种建筑搭配」「星际玩家一键上手」。CoH 系列核心被认可的仍是占点、掩体、侧翼、压制——**基础循环稳，变的是关卡主题**。

**对水浒**：沿用金木/人口/兵营/器械底座是对的；每关只改「争什么、谁压制谁」，不要每关另教一套操作。

### 2.3 英雄/小队短篇要有破局点，且可暂停规划

Shadow Tactics 中文好评：「每张地图几乎都有不同的破局方法」；影子模式让五人指令并行，「想清楚再执行」是爽点；通关后「立刻又买了」同厂其他作。CoH3 也把「战术暂停」做成降低操作压力的辅助（评价偏功能性，不是革命性）。

**对水浒短篇**：至少 2 条**路径或收束实质不同**的解法；读招/冲撞已有，缺的是章节层选择。可考虑短篇暂停下令（若与现有输入不冲突），降低站桩误触。

### 2.4 中文市场：本地化与题材是门票

CoH2 简中差评大量是「没有官方中文 / 禁汉化补丁」；AoE IV / CoH3 有历史叙事与「岳飞没有岳飞」式错位差评。

**对水浒**：四语已做是对的；「不魔改」直接对冲这类差评。技能数值须标明为游戏设计，不反推原著能力。

## 4. 对照水浒现状

### 4.1 已对齐

- 四经营关 + 江州有限补给 + 三短篇：符合「一关一个主题」。
- 不魔改约束：直接对冲 CoH/AoE 题材差评。
- 快活林已有读招/破绽/冲撞：**战斗层**有货，问题在**章节层**。

### 4.2 快活林（维持诊断，修正借鉴来源）

初稿用尖塔「单一解」作类比不当；应改为 **TAB 战役** 与 **Shadow Tactics 短关** 的对照：

- TAB 差评：英雄关无聊、强制、无存档试错、只有一条正确脚本。  
- Shadow Tactics 好评：多角色 × 多破局点 × 徽章目标。

在不扩军前提下仍可做：酒序影响醉意/架势交互；施恩站位成为真实资源；演义徽章（完整酒路/无人倒地/限时）。若仍撑不起独立 RTS 关，再由用户决定插章或降级——不擅自删章。

### 4.3 经营关

Northgard/TAB 共同点：扩张与补员的**下一波立刻兑现**；拆外营停止出兵要「看得见」。连环马把反骑做成可选编队配方，而非唯一正解。

### 4.4 经典 30 波

TAB 生存模式好评来自「平衡推图与防守」；战役差评来自科技死局与无喘息。对应：

- 明牌波次预警 + 20–25 波喘息窗口 + 终波综合考试。  
- 若有科技/成长，避免「点错就软锁」。  
- 失败给可读死因（哪路被破、补给断了、英雄站桩）。

### 4.5 操作底线（CoH3 / Iron Harvest 教训）

- 高惩罚命令（撤退/强攻）不与常用键绑死且可改键。  
- 寻路与自动索敌不能拆己方建筑/误攻关键目标（项目已有 `campaign_no_auto_target` 方向，需持续防回归）。  
- 单位「有没有在干活」要有反馈，避免 Iron Harvest「不知道单位有没有干活」。

## 5. 优先级（玩法向）

**P0**：真人 3–5 人首通；快活林结构评审（不魔改）；崩溃/帧；保存入口开放前的阶段重试。  
**P1**：经营关两条实质路线真人对照；30 波明牌与喘息；英雄机制异质表；短篇演义徽章。  
**P2**：图鉴/四语复核；公告与实际功能一致；先修玩家可见阻断再堆美术。

---

## 6. 一句话原则

**合格 RTS = 可读压力 + 有代价的选择 + 失败可归因 + 玩家时间被尊重（存档/重开/键位/寻路）。**  
**水浒加分 = 原著不魔改 + 英雄辨识 + 短篇/经营节奏交替。**  
战役被对战或 DLC 牺牲，是 CoH3/TAB 的共同差评源——我们单机战役验收优先。

## 8. 深挖：三款核心作品的机制拆解（2026-09-14 追加）

只拆和水浒三种玩法（30 波 / 经营关 / 英雄短篇）能直接对上的心智模型。

### 8.1 They Are Billions — 生存扩张循环

**核心张力（好评）**：推图太慢 → 地盘小经济死；推太快 → 惊动大块头/尸潮暴毙。  
玩家复盘：「前期游侠+弩车清安全区 → 扩地吃经济 → 狙击+电塔清怪 → 主力打老王，尸潮用塔弩守」。  
暂停被夸「给 RTS 发暂停是天才」——单机生存 RTS 允许暂停规划，是降低「手速门槛」的合法手段。

**核心差评（战役）**：

1. 科技树点错 → 软锁，几十小时存档废掉。  
2. 英雄关（点选潜行/找物）又臭又长，还和科技点强制挂钩。  
3. 无存档/无快速重开/失败还记过，试错成本像铁人模式。  
4. 感染雪球：一只漏进家 → 建筑爆怪 → 连锁崩盘，挫败「拉满」。  
5. 多线压力：边界变长后信息量爆炸，传统 F2A 玩家不适应。

**可迁移**：

| 原则 | 水浒落点 |
| --- | --- |
| 推进与防守的钟摆 | 30 波不是纯守家：可出门清外围/断援，但要付回来的代价 |
| 允许暂停规划（单机） | 短篇读招、经营总攻前可考虑战术暂停；不进对战 |
| 禁止不可逆软锁 | 战役成长/解锁若存在，必须可预览、可重置或有「本关需求」提示 |
| 短篇不学英雄关 | TAB 英雄关是差评重灾区；快活林若变成强制找茬/单英雄拖时间会翻车 |
| 雪球要可侦察 | 漏一只就满盘皆输只能用于「应有预警」的高压波，不能无预警偷家 |

### 8.2 Company of Heroes 2/3 — 位置、掩体、小队价值

**好评核心**：不是拼人口，而是「一挺机枪放在对的位置能停住整队」；单位损失有痛感（乘员、模块、修理）；每关主题不同（突破/死守/抢攻）；指挥官/学说改变同一阵营的打法。

**CoH3 的教训（差评）**：

- 战役被对战平衡和 DLC 牺牲：「主玩战役的玩家不是人吗」。  
- 意大利大地图战略层：有人要规模感，有人觉得「管理负担、和即时战斗衔接差」。  
- 战术暂停：有，但只是辅助，不是救世主。  
- 键位：撤退与倒车绑死 → 毁灭性误触，几年不改。  
- 题材魔幻（B1 打爆虎式）→ 出戏差评。

**可迁移**：

| 原则 | 水浒落点 |
| --- | --- |
| 位置 > 数量 | 弓手射界、枪兵抗骑、刀盾顶线、马军绕后：编队和站位要能「以少挡多」 |
| 单位有代价 | 英雄/好汉阵亡成本清晰；普通兵可补，核心人物不可当炮灰 |
| 一关一主题 | 祝家庄攻城、连环马反骑、高俅水陆、大名府内外线——已定方向正确，真人要能「感到换题」 |
| 战役优先于包装 | 未上线的对战/工坊/成就不抢单机战役验收 |
| 键位可拆改 | 高惩罚命令（强攻/撤退/集火）不与常用键绑死 |
| 剧情层别抢操作 | CoH3 战略层争议：水浒章节选关要轻，别在关与关之间塞复杂大地图管理 |

### 8.3 Northgard — 慢节奏、决策在十分钟前

**好评**：「82 岁也能和孩子一起玩」「奖励思考而不是手速」；扩张/养人/过冬互相咬合；输了多半是「十分钟前资源分配埋雷」，不是这一波手残。部族换的是**思路**不是皮肤。

**差评**：资源太紧新手懵；崩溃；期待纯 RTS 的人觉得「不像帝国/星际」。

**可迁移**：

| 原则 | 水浒落点 |
| --- | --- |
| 失败延迟兑现但可归因 | 经营关输了要能回看：是没断援、没护工、还是器械拖太晚 |
| 降低 APM 门槛 | 单机战役允许慢一点、想清楚；英雄技能与自动集结可减轻多线 |
| 玩法异质 ≠ 数值皮肤 | 章节差异：有的关缺马、有的关缺水、有的关缺钱——逼不同编队 |
| 设定预期 | 商店/教程写清「英雄带队 + 经营战役」，避免被当成纯电竞 RTS |

### 8.4 三种玩法对照表（直接可当验收问题）

| 验收问题 | 30 波 | 经营关 | 英雄短篇 |
| --- | --- | --- | --- |
| 本局你做的最重要的 1 个决策是？ | 波次前扩营还是补员？ | 正面器械还是断援侧攻？ | 酒序/站位/读招时机？ |
| 输了能指出原因吗？ | 哪路被破/没预警 | 哪十分钟埋的雷 | 站桩/没躲冲撞/施恩被打 |
| 有第二条实质不同的解法吗？ | 防守反击 vs 出门清源 | 至少两条路线 | 酒路 vs 直挑须改变局面 |
| 无事可做的段落？ | 波间空窗 | 等钱等木材 | 赶路/读条 |
| 试错成本？ | 中段重试/存档 | 阶段存档 | 重打当前关（已有） |
| 键位/误触/寻路？ | 编队与集结点 | 工人与器械 | 拳脚技能与走位 |

## 9. 对快活林的深化（仍不魔改）

TAB 英雄关差评 + Shadow Tactics 好评，夹出一条窄路：

1. **不要**做成 TAB 式强制单英雄长关或找物。  
2. **要**让「喝几家、什么顺序、是否练步、施恩放哪」改变蒋门神架势节奏与反击窗口——这是**同一场决斗的不同战法**，不是新剧情。  
3. 演义徽章（完整酒路/零倒地/限时）提供重玩，不挡核心通关。  
4. 若真人试完仍觉得「只有一条路」，再交用户决定插章/降级，而不是硬加军队。

## 11. 经典战役教科书：星际 / 魔兽 / 帝国 / 红警（2026-09-14 追加）

星际2、魔兽3 本身不在 Steam 商店抓评测；本节战役原则综合：公开战役设计常识 + 本轮 C&C 重制、帝国II DE、神话时代、全战三国、赏金奇兵3 的 Steam 样本对照。不把常识写成「本轮实玩评测」。

### 11.1 星际争霸 II：一关教一件事 + 类型轮换

战役被公认为「单机 RTS 教科书」，结构大致是：

| 模式 | 玩家在练什么 | 水浒可对应 |
| --- | --- | --- |
| 建造进攻 | 完整经济循环 | 祝家庄/连环马/大名府/高俅 |
| 固定兵力突破 | 微操与走位，无等钱 | 野猪林护送、黄泥冈押运 |
| 防守/生存 | 塔位与资源分配 | 经典 30 波 |
| 英雄小关 | 单英雄技能 | 快活林决斗、武松拳路 |
| 特殊规则关 | 整关只改一条规则 | 水陆交替、内应开门、火攻 |

**关键原则**：

1. **每关引入 1 个新东西**（新兵/新技能/新威胁），下一关立刻综合运用。  
2. **不连续三关同一种节奏**——建造关之后接固定兵力，防波之后接突击。  
3. **可选目标**给重玩，不挡主线。  
4. **失败要有明确原因**（SC2 关卡会用提示把威胁点出来）。

对照水浒：八关已有「经营×4 + 有限补给×1 + 短篇×3」骨架，**缺的是关与关之间的节奏轮换是否被真人感知**，以及短篇是否在教经营关会用到的操作。

### 11.2 魔兽争霸 III：英雄 RPG 长在 RTS 上

WC3 战役成功的不是「又一个建造游戏」，而是：

1. **英雄带部队**：经验、物品、复活决策；英雄死了有痛感但不一定全盘结束。  
2. **很多关基地是次要的**：给一支残兵 + 一个英雄，目标是走到某处/救某人/拆某建筑。  
3. **战役本身是多人教学**：操作英雄、技能连招、集火、走位，出了战役直接能对战。  
4. **自定义地图**让寿命指数级变长（水浒暂不依赖，但说明「英雄关」可以成为身份）。

对照水浒：好汉就是我们的英雄池。**短篇关该更像 WC3 英雄关**（小队+技能+明确目标），经营关更像 AoE/SC2 建造关。快活林已经偏 WC3 英雄决斗，缺的是「关卡层选择」，不是再加一座基地。

### 11.3 帝国时代 II：历史战役 = 可读的目标 + 文明差异

AoE II DE 好评（本轮样本）：战役体量大、PVE 爱好者「狂喜」、文明特色兵种、二十多年仍有人回来打人机。差评：学习曲线、寻路、部分战役重复。

战役类型经典四件套：

- **Build & Destroy**：从零建到能推平。  
- **Defend**：守到时间/守到援军。  
- **Fixed Force**：不给基地，给兵和目标。  
- **Escort / Scenario**：特殊胜利条件。

**水浒八关正好可以声明成这四类标签**，菜单和教程写清楚，玩家预期就对齐了（避免「怎么又让我采矿」或「怎么不让我采矿」）。

### 11.4 红色警戒 / C&C：目标极简 + 阵营幻想 + 记忆点

C&C 重制好评（本轮）：「关卡数目量大管饱，几乎都值得反复打磨」；剧情诙谐；关卡手工感强于后来的 RA2 部分内容。差评：寻路、平衡、EA 停更。

红警式战役的可学之处：

1. **胜利条件一句话说得清**（摧毁所有敌军建筑 / 护送 / 生存 X 分钟）。  
2. **阵营幻想鲜明**（苏军钢铁洪流 / 盟军高科技——水浒是「梁山聚义 / 官军围剿 / 地方豪强」）。  
3. **每关一个记忆点**：特殊单位首发、地形杀、彩蛋对话。  
4. **不要用复杂大地图战略层替代关内决策**（CoH3 意大利战役争议的反面教材）。

### 11.5 神话时代：一次投入换多种流派

好评：主神+次神选择让「同一套 RTS」有多种打法；战役 60+ 关；强趣味弱竞技「养老 RTS」。差评：平衡把特色削平、闪退、寻路。

对水浒：**章节差异应改变「怎么打」而不是只改数值**——缺马关、缺水关、缺钱关、内应关。差评里的「削弱特色直到同质化」是要警惕的后期运营错误。

### 11.6 全战三国（对照题材，不是玩法抄）

中文样本极情绪化：有人因刘备线落泪；也有人怒斥「顶着三国名头历史打磨不足」「停更像太监小说」。

对水浒（同样是名著 IP）：

1. **人物命运比地图染色更动人**——图鉴、肖像、章节里的「谁救了谁、谁被擒」要可感。  
2. **故事必须有收束**——半成品战役比难玩更伤口碑。  
3. **历史/原著考据会被较真**——继续「不魔改」红线。  
4. 停更/半成品差评权重极高，与我们「先把战役验收做完再吹内容」一致。

### 11.7 赏金奇兵 3（英雄小队 RTT，补强短篇）

好评：「每打通一关就觉得自己是聪明 B」；技能组合；全杀流与潜行流都成立；角色拌嘴。  
差评：时长一小时起步；认知门槛过后只剩优化。

对快活林/野猪林/黄泥冈：**通关后要有「我用了个聪明解法」的感觉**；演义目标提供第二解；避免关卡长到只剩重复优化。

## 12. 经典战役 → 水浒设计检查单（可直接评审）

### 12.1 关卡节奏（星际式）

- [ ] 本关是否只引入 1 个新机制/新英雄/新威胁？  
- [ ] 与前一关是否类型轮换（建造 ↔ 固定兵力 ↔ 防守 ↔ 英雄）？  
- [ ] 主线目标是否一句话可说清？  
- [ ] 可选/演义目标是否不挡通关？

### 12.2 英雄与部队（魔兽式）

- [ ] 好汉技能是否在短篇关被「教会」，在经营关被「用上」？  
- [ ] 英雄阵亡代价是否清晰且可恢复（不是莫名其妙清零）？  
- [ ] 短篇是否允许「无基地/弱基地」的小队体验？

### 12.3 经营与兵种（帝国式）

- [ ] 本关文明/章节差异是否改变编队配方？  
- [ ] 兵种是否有不可替代用途（枪反骑、弓射界、刀顶线、马绕后）？  
- [ ] 失败是否能归因到资源分配而非「兵不够」？

### 12.4 记忆点与收束（红警式 + 全战三国式）

- [ ] 通关后玩家能复述的一个「名场面」是什么？  
- [ ] 人物命运是否在关内可感（被俘、会合、非致死）？  
- [ ] 战役是否有明确收束，而不是「下一关再说」？

### 12.5 操作与尊重玩家（各作差评交集）

- [ ] 寻路/自动索敌是否误伤？  
- [ ] 高惩罚键位是否可改？  
- [ ] 是否可存档/阶段重试/快速重开？  
- [ ] 崩溃与帧是否达标？
