# 首批四人肖像与图鉴接入

本批落实统一画风、逐人面貌与图鉴优先：宋江、林冲、孙立、扈三娘四张独立肖像替换原图集取脸，常规 HUD 头像通过同一 Art 接口同步。剧情明确指定的囚徒等 variant 仍优先，不覆盖剧情造型。没有修改属性、技能、关卡、碰撞或存档入口。

## 人物与来源

采用内置 imagegen 逐人生成并迭代，四张选定原图均为 RGB 1254×1254 原始字节；Godot 标准导入限制 1024×1024 并开启 mipmap。没有裁图、缩放重编码或修改生成原图。六次生成包含扈三娘和宋江各一次未采用初稿，提示词、来源 SHA 与原稿保留在[生成契约](../tools/contracts/codex_identity_20260913/README.md)。

| 人物 | 这次强化的辨识点 | 保留的游戏设计 |
| --- | --- | --- |
| 宋江 | 深暖褐肤色、宽额、短须，避免与孙立浓须同脸 | 黑巾、金褐袍 |
| 林冲 | 宽颌、浓眉、清晰髭须和颊颏须 | 束发、黑金甲、蓝领巾 |

| 扈三娘 | 白净面色、金钗、红衣甲衬、双兵器提示 | 银甲金饰与具体束发方式 |

依据一百二十回本第7、18、48、49、55、63回逐项核查，具体来源与原文明写/保守设计分界见[原著审查](../qa/codex_identity_20260913/static/source_identity_review.md)，选定四图的独立目检见[候选审查](../qa/codex_identity_20260913/static/candidate_portrait_review.md)。本批没有重写全库生平，也不把具体服色、五官补足全部宣称原著明写。

## 图鉴行为

图鉴新增动作朝向选择：东南、西南、东北、西北。已接入四向资源的角色按所选方向读取移动和攻击帧；攻击缺失沿用同向移动/静态回退。旧角色保留原先无方向取图链，塔保持八向自动转动。新增五个界面词条同步简中、繁中、英文和日文。

新四向预览使用现有 draw_scale / draw_offset_px 和 Atlas 虚拟画布信息，移动、攻击及四个方向共用内容边界与尺度，地面锚按同一整组内容包围框稳定定位，为脚下内容保留空间，避免固定底部18像素导致预览过小；按4fps展示，切换方向重置帧序和相位。旧图保持原有居中与6fps。图鉴只改变预览，不修改战斗动画。

## 验证与未完成项

具体最终批次、检查数、13张原生截图和人工目检范围见[本轮 QA](../qa/codex_identity_20260913/README.md)。采用工程外冻结源码、独立玩家目录和单一 Godot 锁，显式复用已成功导入的资源缓存，不称全新导入验收。早期两轮诊断失败及原因保留。

宋江战斗小人肤色仍偏浅；孙立战斗头饰与脸须仍需后续统一。这两项不能因图鉴肖像更新算作已解决。低帧马步、全库肖像/生平逐条核查、普通兵动作缺口仍开放；此前9/164只是四向基础动作文件覆盖。本批不新增 Steam 包或正式发布。
