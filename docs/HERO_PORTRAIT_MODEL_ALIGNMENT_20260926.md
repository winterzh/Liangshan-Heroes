## 核对范围与基准

用户在头像统一后要求与已经制作的四向模型对应。本轮复核本日补图的八名人物：吴用、花荣、杨志、李逵、卢俊义、关胜、秦明、呼延灼。上轮“HUD 与图鉴一致”只证明两个界面共用头像，不能证明头像与身体造型一致。

当前八人中，李逵有独立通用四向源图；其余七人的通用模型仍使用旧动作条，方向参数会回退到相同来源。黄泥冈、江州、大名府等剧情四向只代表对应剧情变体，不能计为该人物通用战斗模型已经补齐。

## 边界与待办

- 本轮改头像，未修改任何战场身体或动作资源；标准头像继续由图鉴、HUD 和英雄栏共用。
- 江州李逵的赤膊剧情、卢俊义被缚/获救的布衣等仍保留剧情语义；标准头像不随剧情更衣。人物身份一致与衣服逐状态一致分别判断。
- 呼延灼当前旧武器画成刺锤，本轮为贴合在用模型沿用其外形。这不代表“双铁鞭”设定已获校正或原著验收；后续补通用四向时，应统一修订身体与头像的武器，避免只改一侧。
- 七人的通用四向缺口继续开放。本轮截图中四个方向都能出图，不等于四张独立方向已完成；对照图和 JSON 明确区分。
- 头像是身体造型的半身绘画演绎，不声称低分辨率精灵与头像的五官逐像素相同。细节相似性由并排截图目检，哈希仅证明来源身份。
