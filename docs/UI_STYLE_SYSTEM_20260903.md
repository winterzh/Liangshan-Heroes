# 全项目 UI 统一风格（2026-09-03）

## 当前状态

已在本地源码接入“克制宋韵”统一主题。它覆盖主菜单、二级菜单、八幕选关、战斗 HUD、任务面板、暂停/结算、设置、英雄图鉴、据守数值编辑器和场景编辑器。没有修改玩法数值、存档格式、人物美术、Steam 发布目录或平台状态。

## 视觉基线

| 用途 | 色值 |

- 普通控件使用深墨底、1 像素哑铜描边、2—4 像素小圆角；不再使用默认蓝色控件和大面积亮金粗框。
- 绿色、朱砂只保留给完成、危险和明确战斗操作；人物图像、地形色和功能状态不被主题强行染色。
- 连续阅读仍可使用宣纸面板；高频战斗区保持暗底，避免遮挡战场。
- 中文字体继续使用 Godot 自带回退字体，未引入授权不明的第三方字体。

## 接入点

- `scripts/ui_theme.gd`：单一主题来源，定义颜色、按钮、输入框、列表、进度条和滚动条样式。
- `scripts/menu.gd`：主菜单使用 `assets/ui/boot_splash.png` 作梁山背景，并统一所有一级/二级入口与八幕卡片。
- `scripts/hud.gd`、`scripts/campaign_mission.gd`：战斗底栏、任务、消息、技能提示、暂停和结算。
- `scripts/settings_panel.gd`、`scripts/codex.gd`、`scripts/editor.gd`、`scripts/scenario_editor.gd`：工具页和内容页统一继承主题。
- `tools/ui_style_visual_test.gd`：真实渲染五张 1280×720 核心界面，便于后续改动复查。

## 后续新增界面规则

新增 `Control` 根节点时优先设置 `theme = UITheme.shared()`；新增 `CanvasLayer` 时使用 `UITheme.apply_canvas_layer(self)`。只有明确的语义状态才局部覆盖颜色，不复制另一套蓝紫色 StyleBox。
