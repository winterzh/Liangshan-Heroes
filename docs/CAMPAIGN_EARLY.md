## 已实现的事件链

- **野猪林 / level6**：只有鲁智深、林冲、董超、薛霸。移动中的披枷林冲与两名解差只在救援前自行抵达松树；鲁智深实际选择北松林或南芦丛暗跟才有对应拦棍窗口，不跟则林冲遇害。拦棍后收杖解绳、照料双脚为短现场演出，随后四人全部由玩家选择和移动。董超、薛霸夹扶伤脚林冲，鲁智深提禅杖领队；玩家先指挥四人歇脚整队，再发第二条路线共同出林。没有陆谦到场、虚构追兵或救人后的友方自动选路；公人变为可选友方只表示本关临时护送，不代表加入梁山。
- **黄泥冈 / level1**：晁盖、吴用、公孙胜、刘唐、阮小二、阮小五、阮小七七人分别具名。察路摆枣后，杨志到现场盘问，刘唐当面答话；通过后白胜才出场挑酒。非当前角色离开枣担区逼近杨志或纲担会起疑，须让露出破绽的人实际退回自己的枣担并恢复身份。刘唐到甲桶试好酒，再到押队前引注意；吴用到乙桶使用药瓢，白胜须在吴用仍在场时夺瓢倾回，再卖乙桶药酒。引注意后22秒是交接窗口，刘唐离岗、吴用不在桶边或错过窗口均可重接，100秒总歇脚时钟不会重置。15名押送者统一进入 unconscious 非死亡状态；三名指定搬运人各自挑担送出冈，最后全员撤离。主动攻击即使未命中也会使酒计失败，击杀不再是胜利条件。
- **快活林 / level7**：武松和施恩两人出发，没有张团练或无关军团。每家酒望须主动吃三碗；武松以本局四套拳脚技能代替召虎、双刀和后期装束。酒意使拳力增强，同时令步速和出手波动；稳住酒势技能可以短时压下这一风险。蒋门神有可见红圈提示的蓄拳落点和侧移反击窗口，致命伤转为 subdued；之后说清退店条件，由施恩接管完好的酒店。
- **江州 / level2**：西街、南巷分路接近，李逵先动手，击倒两名刽子手后分别解绳。宋江、戴宗以活体引用贯穿逃离检查，任何一人获救后死亡立即失败。获救后可选择西巷近路或南巷宽路，两条路线实际使用不同路点队列。到白龙庙才生成相遇水军，宋江、戴宗分别实际靠近船岸并停留登船，其余幸存救援队随晁盖撤离后才胜利。

## 公共接口使用与数据边界

- 所有任务按钮和烟测均通过 `mission.request_action`，由真实寻路、靠近、停留触发 `on_mission_action`。烟测有活动任务时不抢单；不会通过改阶段、减敌方生命、传送或直接调用胜利来走成功线。
- 使用 `defeat_outcome` / `resolve_story` 区分昏迷、制服和登船；对关键结局的人物只记录一次。失败注入测试会显式制造受伤/死亡，仅验证失败分支。
- `apply_overrides` 仅修改本局 `defs` / `abilities`，不改全局 `Defs`；四向装束由 `art_variant` 指定。
- 本次沿用并调整原地图的可通行任务位置；地图碰撞、任务交互距离和NPC站位必须一起验收。第一轮实际运行已发现并修正野猪林、黄泥冈任务点隔着静止NPC而无法抵达的问题。
