# 战役任务框点击展开

## 玩家操作

每次进入战役，左侧目标区默认显示 `▶ 任务目标` 小按钮。点击展开本关标题、核心目标、可选演义目标、定位按钮与任务反馈；再次点击 `▼ 收起任务` 恢复小按钮。当前战役内切换阶段会保留玩家的展开选择，新一局默认收起。

收起后，详情原先占据的地图区域可正常点击和框选。任务计时、玩家下令后的办理过程与目标状态更新照常进行；重新展开显示最新内容。定位按钮仍只移动镜头，不替玩家下达移动或攻击命令。

## 实现

`scripts/campaign_mission.gd` 保留原 `CampaignObjectives` 外壳，增加不取得键盘焦点的 toggle 按钮和可隐藏的详情容器。收起最小宽度为 148，展开仍为 286（实际宽度由内容最小尺寸决定）；每帧重新收敛控件大小，让隐藏区域退出鼠标命中范围。

`tick()` 继续按战斗阶段控制整个框的显示，详情隐藏不改变任务计时或处理。长目标列表继续使用原滚动区，并从可用高度中扣除新增按钮与间距。战斗结算时整个框一起隐藏。

七份原有详情视觉夹具显式展开目标，维持原来的截图/按钮验证前提；freeplay 文字采集按 `is_visible_in_tree()` 判断，避免把隐藏祖先内的文字误计为可见。专用 GUI 驱动另行验证默认收起及真实鼠标切换。

## 验证与使用

本轮原始结果、实际截图、驱动、精确来源哈希和复现入口见 [QA](../qa/mission_panel_toggle_20260907/README.md)。本项只调整任务框交互，不属于真人战役通关或性能验收。

从本开发工程重新运行 `Play.cmd` 并进入战役加载本改动。源码分支同步与 Steam 构建更新分别记录，本项未包含 Steam 上传或发布。
