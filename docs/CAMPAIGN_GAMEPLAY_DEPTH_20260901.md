## 八关实际改动

| 原著顺序 / 稳定ID | 本批落实的有效决策与约束 |
| --- | --- |
| 野猪林 / level6 | 2026-09-03改为押送队自行前进，以鲁智深的真实站位判定北侧松林或南侧芦丛暗跟。完全不跟则到松树后林冲直接遇害；跟得过近会缩短拦棍窗口，合适距离保留42秒。只保留手动拦棍标记，没有自动派遣按钮或追兵。 |
| 智取生辰纲 / level1 | 押送者麻倒后选择“集中编组”或“逐担派送”。集中编组要求刘唐、阮小五、阮小七先分别到三处担位，全部就位才开放搬运；逐担路线一次只派一人。原三担、具名人物、昏迷结局和旧动作ID保留。 |
| 醉打蒋门神 / level7 | 第二家酒肆后加入一次左右移步练习，不造成伤害；蒋门神交替使用圆形重击和长条冲撞两种真实预警。闪开后出现有限反击窗口，格挡只减伤，不增加生命。仍以求饶、制服和归还酒店结算。 |
| 江州劫法场 / level2 | 原六名追兵改为西巷3人、南路3人两处有限压力；路口允许一次改道。白龙庙后选择李逵或燕顺断后，前队登船后必须显式收回，断后者活着登船才可胜。另修复晁盖单独到庙可提前开阶段、以及点击收回后断后者途中死亡仍可能判胜两项漏洞。 |
| 三打祝家庄 / level3 | 第二打要求宋江退守、林冲拦截、花荣掩护后才能围擒；扈三娘由林冲可见押送至营前交接，不在战场反戈。第三打由顾大嫂救囚、孙立守门、宋江在庄外发令；七名囚犯按4人、3人分两组撤到不同集结点。提前开门或发令会被拒绝，但可补齐条件后重试。 |
| 大破连环马 / level4 | 操练先由唐隆引一名练习骑兵入位并退出钩击线，再完成双人钩镰；正式战斗把原12骑分为前6、后6。第一侧破阵后该侧暴露，预备队必须换到另一侧再诱后6骑。韩滔被擒、呼延灼败走青州的结果不变。 |
| 智取大名府 / level8 | 火号后仍用原11名城外接应者，先后控制主街和牢前两条压力线；第一线需2人，第二线需3人。守军恢复可夺回控制，开牢与撤离会被重新阻断并允许补救。护民越早只引2名追兵，越晚引5名并封东巷，卢俊义、石秀仍须活着出城。 |
| 三败高太尉 / level5 | 第一败增加主港、侧汊两条相连水路；第二败只用一艘火船、两艘接应船和原5艘连船，依次准备、选北/南火点、近距点火、接应撤离；第三败先压制5艘护航中的至少3艘，之后才出现封港动作，再由张顺近船凿船。提前硬冲会被围攻但可撤回补救；水救、返航、真码头交接和生擒仍完整执行。 |

这些改动没有靠加血、无限刷兵、空等或重复长路补时长。黄泥冈仍是15名押送者、连环马仍是12骑、终章仍使用有限船队；快活林蒋门神和既有敌人的生命值未提高。
