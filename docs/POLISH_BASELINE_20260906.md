## 新测量入口与重现方式

需要Python 3.9以上标准库、Godot4.6.3及实际图形设备。Godot路径使用本机忽略配置或 `GODOT_PATH`，也可传 `--godot`；不要将机器路径写入公共工具。

```powershell
python tools/run_polish_performance.py --cases economy defense200 zhu_contact gao_contact --camera fixed --repeats 3 --seconds 60 --label baseline_fixed
python tools/run_polish_performance.py --cases defense200 --camera auto --repeats 3 --seconds 60 --label baseline_auto
```

每条命令串行启动全新Godot进程，四个场景各3次至少60秒；自动镜头只用于确有全托管镜头的驻守场景。一次只运行一项Godot负载。可用 `--allow-short --seconds 6 --repeats 1` 预检工具，但短测永远不能组成基线。输出默认写入新建 `.godot/polish_performance/<label>_<UTC>/`，不覆盖先前证据。

共同条件：1440×900，正常游戏速度1、60Hz物理、关闭VSync且不限制渲染帧率；禁用会改变画面的QA开关，记录已清理的受控环境值。保持标准画面和显示反馈，声音合成完成后才建立战斗，音频播放逻辑仍运行，仅主总线静音。设置和章节成绩文件在前后按字节检查，工具不保存玩家设置。

| 场景 | 固定部署与实际输入 | 测量边界 |
| --- | --- | --- |
| economy | 原生驻守开局，首物理步命令工人交替采金和木 | 120秒第一波之前的经营窗口 |
| defense200 | 原有 `_perf_bench_setup(200)`：六位托管英雄与200名初始敌军 | 允许正常伤亡、生产和AI；不是全程恒定200敌，也不是30波通关 |
| zhu_contact | 当前祝家庄，在正门外明确增加72名普通刀枪弓兵及4辆攻城冲车，首步正常攻击移动 | 人口可超过自然生产上限；只表示拥堵压力，不表示平衡或自然付费路线 |
| gao_contact | 当前高俅己方水陆部队首步正常前进，同时提前发送原有第一批敌军 | 水陆真实伤害都须在测量窗口内出现；不是自然140秒出兵时序 |

每次300个真实物理步热身后，测量完整渲染帧间隔，保留全部原始帧时间、Godot process/physics监视器、渲染CPU/GPU、绘制调用数及每60物理步的单位/血量/任务/镜头轨迹。GPU计数若全部为0会记为不可用，不解释成零开销；不同计时域不能直接相加。同时记录墙钟时间与实际模拟推进时间，负载过高时不能用模拟慢下来伪装成相同战斗时长。

`python tools/analyze_polish_performance.py <本轮输出目录>` 另生成 `segment_analysis.json`，按墙钟顺序保留全部10秒段及尾段，不挑选最好窗口。跨段帧的时长与帧数按占比分摊，P95/P99计入所有与该段相交的完整帧耗时。首轮驻守已显示“早段压力、后段清敌后空闲”会抬高全窗平均FPS，故同时查看最差完整段和单位轨迹。分段是诊断，不替代60秒三次基线或持续压力验收。

固定镜头禁止自动写入和手动输入，并检查位置、缩放、偏移和旋转漂移；自动镜头保留正常取景和屏震，禁用鼠标事件输入，任何实际键盘接管使样本无效。自动镜头须在测量窗口内实际工作。

## 可比性和验收解释

基线是相同初始布阵、种子5088120与物理步输入计划下的统计比较，不声称战斗逐步完全重放。现有音效/音乐仍消费全局随机流，李逵巨斧效果仍在渲染回调中结算伤害；这些实际变异来源单列，后续恢复存档和表现优化时须处理。每组三次初始部署与输入计划指纹必须一致，所有计划重复均有效才有 `baseline_eligible=true`。

来源收据覆盖生产脚本、场景、美术/动画、导入配置及内容目录、工程和测试助手：文本按LF归一，二进制逐字节SHA256。每场开始前和退出后都核对，期间任何来源变化会保留报告并使样本无效。源码或资源有变化时另起新批次，不能混用旧指纹下的结果。

`acceptance_eligible` / `baseline_eligible` 只表示能否作为至少60秒、至少3次的测量证据，不表示帧率达标。中间工程目标仍是压力持续30FPS、P95≤50ms；最终目标仍是正常玩法60FPS、P95≤16.7ms、P99≤33.3ms。不得将宽松阶段指标、短测、局部函数计时或单次最佳成绩替换最终验收。
