## 修复

- 北侧大路铺设顺序覆盖了六个墙体格：北墙 (19..23,20)、东门旁 (31,29)。大路改从寨外通往东山关，铺路后重建共同院墙边界；经典与自定义据守共同修复。运行中的旧地图需重开战斗才使用新布局。
- 正式 Godot 模板的原生回调名称为空时，保存校验仍检查回调类型、目标、信号及参数；恢复安排到安全的 process_frame，避免鼠标请求落在物理帧。
- 工坊安装处理器兼容原生元数据的两个参数及实际事件的四个参数，安装完成后清除等待并刷新列表。
- Windows PowerShell 稳定性启动脚本补 UTF-8 BOM，避免中文按旧编码解析失败；包装器缺报告时返回明确诊断。
