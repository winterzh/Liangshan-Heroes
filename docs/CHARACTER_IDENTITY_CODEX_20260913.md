# 角色辨识与图鉴美术标准

2026-09-13，用户明确要求：“风格要统一，但是脸不能都差不多，要符合原著，图鉴也是重点”。本文件约束后续角色制作和已有角色复核，覆盖头像、图鉴、战斗动作及剧情换装。现有动作通过收据继续有效，但不据此关闭全库肖像、原著或图鉴验收。

## 统一画风，逐人确定面貌

统一当前游戏的绘制语言、明暗处理、材质质感、细节密度和清晰度；肖像另统一构图、光线、背景与裁切尺度。采用相同风格参考，不能让所有角色继承同一张身份参考脸。

每名有名人物先建立身份卡：原著依据、面部识别点、体型轮廓、服装与兵器、不同剧情状态、参考图和禁止项。脸型、眉眼、鼻口、胡须、肤色、年龄感与气质按人物分别确定；不能仅靠换胡子、换衣色区分人物，也不能为了差异自添原文没有的伤疤、胎记或族属。原文未明确的具体五官列为保守美术设计，不假称原著明写。

同一人物的图鉴肖像、HUD头像、战斗人物和剧情换装必须能互相认出；不同朝向或动作不能换脸、变年龄、改变体型与惯用装束。原著明确的剧情换装与状态分别记录，保持面部身份。相似题材人物同屏对照检查，避免都画成同一种俊脸、猛将脸或年轻女性脸；没有原著依据时不强行用丑化或夸张生理差异制造辨识度。

## 原著依据

沿用[原著合同的判定顺序](ORIGINAL_ART_CONTRACT_NEXT_BATCH_20260902.md)：原文明写、保守设计、玩法压缩分别记录。制作前逐人核对一百二十回本相关回目，记录确切章节与可回读来源；原文优先于旧图、旧提示词和影视印象。已有条目列出回目不等于具体面貌已经核对。

原著没有写清的细节可以克制补足，但不能靠戏剧化装备、玄幻装饰或现代妆发替代人物特点。游戏技能与数值明确作为游戏设计，不反推为人物生平或原著能力。

## 图鉴与制作顺序

图鉴是本轮重点交付面。先逐人核对肖像与身份，再同步战斗和图鉴展示；图鉴的价值包括看清人物、辨识身份、查看动作和阅读有依据的生平。大幅肖像不能仅以小头像放大“能显示”作为质量通过。

当前源码核对基线为`ed684b65`：

- `scripts/codex.gd::_select`使用`Art.portrait_texture`，失败才回退头像/立绘；头像存在不等于它已与新战斗形象一致。
- 同函数以不传方向的`Art.unit_anim_frames(key, "walk"/"attack")`读取动作；`scripts/art_db.gd`默认方向为空，因此新四向TRES不会自动成为图鉴展示来源。
- `AnimBox`目前以固定6fps居中缩放纹理，没有采用战斗绘制的`draw_offset_px`和`draw_scale`。后续接入新帧时须处理虚拟画布与脚锚，避免跳动、忽大忽小及截断；不能只替换文件名即宣布同步。
- `Bios`、`LoreData.CHAPTERS`已提供生平、座次和回目说明入口；后续逐条复核内容与画像，不能把已有文字直接算作新一轮原著验收。

下一批先以宋江、林冲、孙立、扈三娘建立同屏身份对照和图鉴一致性样本，处理新旧取图问题；样本明确后按出场频率扩展人物与官军斩字军。普通兵动作缺口继续保留，但不优先于本轮新增的图鉴和身份要求。
