## 合同

捕获一次遍历完整子树，保存原父子关系和兄弟顺序。箭矢/飞斧占用同一节点编号空间，不会先过滤掉再另行插回。普通Bolt/TrapMarker的共享引用token因此仍指向唯一节点。专用模块记录保存在对应行的 `values.state`，其节点状态必须与外层节点状态完全相等；重复表示不允许出现冲突。

宿主显式传入受信的两个适配器，存档不能指定脚本、资源或工厂。未传入适配器时遇到对应节点仍拒绝整图。飞斧捕获要求同一Battle，恢复要求宿主提供脱树的目标Battle。渲染覆盖、额外子节点、未登记类型和权威弹道上的额外信号连接均拒绝。

整个图与全部单位引用先校验，再分配禁用且阻塞信号的节点。箭矢/飞斧绑定失败时释放临时节点与已准备图；不接触原世界。失效单位引用使用调用者提供的共享占位对象，全部绑定后必须释放；权威弹道仍持有活占位对象时整图激活拒绝。激活前检查所有节点的状态、类型、父子顺序及飞斧Battle归属，防止改动后的半图开始运行。

构造参数在原五项之后追加 `projectile_adapter`、`axes_adapter`，原有调用不变。恢复宿主按以下顺序使用：

1. 从受信源码构造 `run_projectile_state` 与 `run_li_brawn_axes_state`；飞斧纹理由宿主提供固定对象，不能从保存路径加载。
2. 构造 `run_visual_graph`，传入目标Battle、建筑纹理表和两个适配器。调用 `prepare(record, content_version, id_to_unit, expired_unit)`。
3. 将返回root赋给目标Battle.fx_root；按已有协议绑定地面火计数/退出信号（含0计数）。全部图绑定后释放共享失效单位及Fx占位对象。
4. 在暂停树中按原顺序挂载，只调用一次activate；整个世界就绪后才恢复运行。源码/引擎/内容身份、完整屏障及世界事务仍由外层负责。
