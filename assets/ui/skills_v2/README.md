# 驻守战核心英雄技能图标 v2

本目录包含宋江、林冲、花荣、李逵、公孙胜、武松的 24 张技能图标。运行时使用 256×256 单图；`atlases/` 保留六张未经覆盖的生成源图，便于后续重切或统一调色。

- 生成方式：Codex 内置 ImageGen
- 生成日期：2026-09-04
- 统一规格：四宫格、透明外缘、暗漆木/旧铜框、矿物色、北宋历史幻想 RTS 风格、无文字
- 接入范围：`scripts/hud.gd` 中 `HeroSlotButton.ART_ICON_PATHS`
- 回退规则：未列入映射的技能继续使用原矢量图标

六张源图分别围绕以下四招生成：

- 宋江：战场鼓舞、忠义双旗、火攻连营、仁义号令
- 林冲：破阵枪、回马横扫、禁军教头、豹头点将
- 花荣：凌空闪、箭雨、五连定身、百步穿杨
- 李逵：双斧回旋、莽撞冲锋、蛮力、嗜血暴走
- 公孙胜：黑雨、冰墙、百兽奔袭、画龙点睛
- 武松：驱使双虎、三碗酒、双戒刀、醉神大闹
