# 祝家庄原生方向门楼来源

四次内置 image_gen.imagegen 调用的完整提示词、输入、输出SHA及选择结果见 [generation.json](generation.json)。三张中间原图只保留来源链，生产只使用末次RGBA；生产原图与工具输出字节一致。参考图是仓库中已留存的实机画面，不是新的外部素材授权凭据。

首次及第二次为RGB棋盘格；第三次RGBA轮廓碰边；第四次保留完整可见轮廓。预览中的金色背景大部分位于alpha=0，不将预览代替实际alpha与游戏合成检查。未使用Python裁图、去背景或重新编码；Python/Pillow审计只读像素，Godot执行标准导入和运行时绘制。

这份来源链不补齐项目早期美术的历史授权/来源缺口。普通电脑直接导入生产PNG即可，不需重新生成素材。
