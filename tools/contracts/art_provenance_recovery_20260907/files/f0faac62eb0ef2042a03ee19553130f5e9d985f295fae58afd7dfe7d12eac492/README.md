# 大名府获救卢俊义四方向重画

日期：2026-09-03

## 原著和游戏边界

主依据为维基文库百二十回本[第六十六回](https://zh.wikisource.org/zh-hans/水滸傳_(120回本)/第066回)。原文写柴进在牢中“便去开枷，放了卢俊义、石秀”，随后卢俊义立即引石秀等人奔回家中，天明时与众头领会合。由此本批只确定：获救造型必须去枷、去绳，能自行站立和奔走；不得继续戴枷，也不应画成重伤不能行动。

原文没有逐项规定获救瞬间的衣色、鞋袜和发式。本项目为保持牢前牢后同一人物连续，沿用既有大名府卢俊义的方正壮年脸、黑髯、灰白长袖粗布衣、深灰裤和旧布鞋；这是游戏造型连续性，不冒充原文逐字描写。不给他提前换铠甲、官服、披风、马或武器，也不添加断肢、大片血污等原文没有的伤势奇观。

## 清理与生产边界

网页只允许对原图执行一条确定性规则：`alpha<=15 -> RGBA(0,0,0,0)`；`alpha>15` 的RGBA必须逐字节不变。下载回收后由独立脚本逐像素验证。之后本地只允许固定四列三行内的连续矩形裁切、全12格共用的等比缩放、透明补边、两帧横排、PNG/JSON编码和逐字节复制；不得镜像、补画、遮罩、连通域抠图或清除其他Alpha像素。

生产接入前必须完成人工候选图检、旧生产文件备份、Godot导入、运行合约、真实图形实拍、覆盖审计和文档回写。本批不导出，不修改Steam发布目录。
