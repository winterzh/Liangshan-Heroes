旧投石车 PNG 和攻击资源来源仍保留。`jobs.json` 留存完整提示、选择、原生 SHA 与实际参考链；`native_inputs/` 保存末态返修实际使用的父图，`guides/` 保存轮辐相位图及只在新画布绘制该图的生成器。`prepare.py` 只读 alpha 并写元数据，不修改生产位图。悬臂高低不能改变底盘比例，缩放依据同方向待机的底盘宽度。
