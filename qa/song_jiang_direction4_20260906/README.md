# 宋江四向接入验证

当前冻结证据使用 Godot 4.6.3，图形测试为 Vulkan / RTX 3070 Ti。仅验收本批通用宋江四个动作方向的接入和回退边界。

| 检查 | 结果 |
|---|---:|
| 宋江资源、反例、剧情变体、实际移动/近战/死亡 | 250通过 |
| 原生字节、来源依赖、alpha、导入和固定区域 | 195通过 |
| 驻守路由与旧动作优先 | 8通过，452个旧动作场景 |
| 四种现有高频官军动作 | 257通过 |
| 门墙几何/遮挡 | 46通过 |
| 孙立群选、停留、取消、完成及失败分支 | 22通过 |

`runtime/unit_pose_matrix.png` 为20个实际 Unit 固定姿态，逐格人工检查：身体朝向、持剑手、衣服、脚底及跪倒/躺倒尺寸一致；没有棋盘格或光晕。它是便于对照的夹具。`runtime/live_melee.png` 为驻守地图上的真实移动后交战；伤害及死亡释放在同目录报告中逐向记录。图中的临时帧率不能用于性能结论。

`regression/` 保存原官军、驻守回退、门墙和接应回归；原官军工具仅在忽略目录创建改变输出路径的副本运行，副本保留为文本证据。`inventory/` 保存当前164定义清单；`sources.json` 是本次只读来源检查；`receipt.json` 固定本轮相关输入与证据的哈希。

本批没有全战役/30波真人验收，没有将历史严格美术来源清单自动标记完成。宋江仍是1/2/3/4帧的基础动作，hurt没有专门新帧；全库及发行目标继续开放。复现命令与依赖见 [说明](../../docs/SONG_JIANG_DIRECTION4_20260906.md)。
