# 第二轮伤害动作取样失败

本轮已使用修正后的西北低位劈斩与东南倒地锚点。28 张截图产出，600 项中只有东南“命中选择劈斩帧”未通过，未继续作为最终验收。

[报告](yang_zhi/report.json)记录东南目标已承受20点伤害，但渲染帧定时器返回时 `_lunge=0.253333`，角色进入收招待机；其他方向取到劈斩。生产代码在物理帧结算伤害，原测试在渲染定时器后读动作，可能跨过多个物理帧。

修正仅在共享 QA 添加 `MeleeHitProbe`：以物理优先级1000在正常单位更新后读取首次实际HP下降时的动画和lunge，保留同一“必须选择manifest劈斩”断言，不改变时间倍率、游戏数值或单位逻辑。重新冻结执行，不把此轮记为通过。

本目录保存[收据](receipt.json)、[日志](yang_zhi.log)、[报告](yang_zhi/report.json)、东南命中截图与修正后矩阵第二页。完整第二轮工程与其他截图保留在收据内工程外路径。
