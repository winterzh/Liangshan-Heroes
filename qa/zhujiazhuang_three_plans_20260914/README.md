3. 资源账本：经 `Battle.spend/add_resources/refund` 观察钩分别记收入/支出/退款，并独立对账。

5. 损失：曾存活且从单位表消失计数（不与 `died` 双计）。  
6. 挂起：墙钟超时 + 收据在场景清理前写出。

## 观察（控制器约束下的对照，非最优打法）

1. **断援三局整局外营出击 = 0**，且 3/3 胜利（341–404 秒）。  
2. **扩矿三局均入账北矿金 333–403**，但仍吃 3–4 次外营出击，3/3 战败在门/塔阶段，未破大营。  
3. **内应三局 3/3 胜利**，偏门打开，出击 1–2 次；常意外占北矿。  
4. 在本自动控制器下：**只扩矿不值得**（收入未转化为胜势）；断援与内应可完成核心。  
5. **不能**据此断言真人不能用扩矿打赢，或内应/断援必然更优。
