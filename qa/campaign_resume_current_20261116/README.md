## 连环马实际续玩协议

[run_lianhuanma.py](run_lianhuanma.py)使用独立host绑定新来源；[workers.json](workers.json)记录原worker和普通操作策略SHA。`base/terminal/policy/bootstrap`保持原字节；策略的逆补丁还原后须与原driver逐字节一致，不能改变其他流程和断言。策略SHA为 `bf8390c57469659e1fece50401aa4a8e1cc5f934b4e3883d62de457660786163`。

顺序为：

1. 正常招募中的保存并退出。
2. 独立进程继续，训练完成，再保存退出。
3. 再次继续，通过普通指令自然完成整关；保留原四项演义要求，包括十二骑下钩。
4. 独立进程拒绝终局旧槽，并核对终局及奖励幂等。

全程正常速度、Steam关闭、`CAMPAIGN_QA`为空；实际生产 SaveAndExit/Continue、私有四环境目录和原生显示均由原worker检查。不注资源、位置、伤害、胜利或完成状态。host核对每个真实进程PID、报告、来源身份和前驱SHA。失败原件保留，不把核心胜利或前两进程成功算作整条通过。

## 使用

以下参数由本机提供，不把引擎或共享锁路径写死进公共工具：

```text
python -X utf8 -B qa/campaign_resume_current_20261116/prepare.py --native-root <保存原helper及构建证据的工程绝对路径> --prepare
python -X utf8 -B qa/campaign_resume_current_20261116/prepare.py --import-cold <新候选绝对路径> --godot <Godot.exe> --lock <共享引擎锁绝对路径>
python -X utf8 -B qa/campaign_resume_current_20261116/run_lianhuanma.py --candidate <已通过首次冷导入的候选绝对路径> --godot <同一Godot.exe> --lock <同一共享锁绝对路径>
```

不传 `--prepare/--import-cold` 的准备工具仅检查来源，不写文件、不启动引擎。每个候选最多一次冷导入；来源或工具变化后新建候选。上一轮失败收据不能用于新来源资格。

M1及八章计划仍未完成；自然胜败、其余章节恢复、真人体验、性能/设备、发行资格依各自实证判定。
