# 杜兴人形近景头像候选

内置imagegen生成一份[独立头像原PNG](native_originals/portrait_v1.png)，[精确提示词](tool_prompt_portrait_v1.json)与引用摘要保留。原字节复制，没有本地绘画、抠背景或重编码。现用九宫格、走图、角色状态与技能路由保持；[静态比较页](readability/review.html)和[实际截图](readability/review.png)可直接查看。

## 原著依据

本轮实际取得维基文库《水浒传》120回本第47回，保存完整原文/原始HTML与摘要。第7行明确“因为他面颜生得麤莽，以此人都叫他做‘鬼脸儿’”，同时说明中山府人氏、晓得拳棒；第9行表明李应将大量财物事务托付杜兴；第27行有“杜兴也披一副甲，持把枪上马，带领二十馀骑马军”。精确引文/行号见`canon_basis.json`。

新稿表现粗犷的人类面貌，不画鬼怪、鬼面具、獠牙、发光眼或法术。具体眉形、粗鼻、下颌、肤色、短须、头巾/发髻、甲色与纸纹背景是参考现用人物的美术设计，不称原著逐字规定。头像不展示兵器是近景构图选择，不代表此人任何剧情中都无武器或同一身衣甲。

现用头像/走图中的弯刃、长柄刀与虚空/瞬移等技能，本批没有据第47回批准；其现用定义另存待审快照，不改游戏行为，也不以一章证据断言全书绝无其他兵器。

## 实际检查

已有Edge与私有Playwright 1.64.0隔离显示三个原图，浏览器实际解码并以WebCrypto核对SHA；DOM实际计数13个显示实例，含旧头像/新稿/走图首帧与256/128/96/64/32像素对比。独立profile进程已退出，页面错误0；未接触用户登录profile或修改系统配置。HTML每源只嵌入一次，profile/依赖不进Git。

原稿与1800×1450对比截图已直接目检：脸部比旧半身头像更大，64像素眉眼、鼻梁、短须与头巾较清楚；32像素可辨粗轮廓，仍不接受对全角色库可靠认人。头巾/发髻完整，但上缘留白小于提示预期，实际UI边框裁切须原生检查；服色与当前身体大类相近，不宣称逐像素五官/甲饰完全同一。

本批仅来源/静态阅读候选，生产采用0，没有Godot、真实图鉴/HUD/Unit、四语言/多分辨率、包内或性能资格。129/16/81与HUD、26份其他待验证本地文件保持；原Godot单一等待队列与外来占用标记未动。人物其他动作、场景、船只、特效、UI与性能的全库目标继续，main/Steam未操作。
