# 施恩四向短棒攻击来源候选

内置ImageGen独立生成SE/SW/NE/NW四张RGBA原图，每张包含蓄势、下击、收招、复位四个关键姿势。16个姿势均直接看过原图；脸/衣甲/头巾/双短棒沿用本批施恩待机设计。保留原PNG字节、完整提示词、实际引用来源SHA与生成标识，未镜像、抠底或程序补画。

`source_manifest.json`只绑定来源和采样区域，不是SpriteFrames或游戏接线。NE收招棒头越过几何中线，最初固定半宽采样触边失败；原错误另保存。新边界移入真实透明间隙，所有四图的16个主体/武器均完整、各采样范围有至少8原生像素的实质alpha留白，全部alpha>=16前景恰好归属一次。未丢弃越界棒头或放宽检查。PNG像素不变；角色身体的统一显示比例和连续攻击时序仍须后续验证。

生产目录含`.gdignore`，当前未导入、未接入战斗。现行快活林施恩仍为原非战斗角色，本批不开放其攻击。原普通战斗回调、四向攻击时序、伤害命中、受击/死亡、旧头像一致性及全美术仍未完成。

复核：`python -B tools/prepare_shi_en_attack_candidates_20261015.py`。仅第一次接收后使用`--prepare`创建来源清单。`candidate_preview.html`仅在浏览器按原区域等比采样，可暂停和逐帧查看；浏览器画面不替代Godot原生或战斗资格。
