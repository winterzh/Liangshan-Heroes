## 限制与后续

这是暂停、关闭迷雾、移到目标处的界面验证，截图 FPS 不代表正常性能，也不证明战斗/手机验收。HUD 使用物件原纹理和名称文字；场景内牌匾文字继续由世界绘制器叠加。遭遇战大厅附近的建筑外观重叠须继续检查是否来自重复模型或院落布置，不将“全局回退保持一致”当作整座场景视觉验收。
