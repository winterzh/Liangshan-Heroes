## 恢复本轮删除的重复文件

在开发工程根目录，先向新目录恢复所需批次，例如：

```powershell
python qa/storage_cleanup_20261026_round2/restore_duplicates.py qa/storage_cleanup_20261026_round2/plan.jsonl.gz . 'D:/CodexTemp/shuihu-round2-restore' --prefix '.godot/huangnigang_full_package/20261018_153917_4c10b0cd/project/' --from-git
```

默认优先用原保留文件，字节不符时读取指定Git blob；`--from-git`强制使用Git。`--verify-only`只校验；`--prefix`可选目录或一个精确文件。恢复器拒绝路径越界、reparse、LFS指针和覆盖不同文件，保留原mtime并核最终SHA。只补本轮映射内文件，不碰留在原处的独有文件。
