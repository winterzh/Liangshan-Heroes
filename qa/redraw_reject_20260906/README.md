# 重绘提前排除：验证证据

对应[实现说明](../../docs/REDRAW_REJECT_20260906.md)。生产候选仅移动两个函数内的既有拒绝判断；本目录归档局部验证及12个至少60秒正式对照，不表示性能门槛通过。

- `state/`：最终3,264对、7,948项状态检查及来源收据，未使用实际绘制。
- `counters/`：固定/自动镜头、206/326/506初始机动单位各10秒的计数、人口轨迹、脚本、来源和原始字节恢复收据；探针会影响耗时，不能作为FPS样本。`counter_preflight/`是两秒入口。
- `render/`：第四次、迁移前585项实际渲染检查；70组、1,400对原始RGBA一致，保存视野边缘和重入代表图。使用可控姿态、真实高度场/逻辑视口和相同模6的实际单位编号。
- `timing/`：121项、38种配置的完整方法计时。`window_totals_summary.json`取每个完整12步窗口的耗时总和，不使用可能偏向stride拒绝分支的单步中位数。
- `comparison/`：旧/候选×固定/自动镜头×3轮，共12个至少60秒窗口，均满足完整性与统计比较条件；保留逐帧时间、每10秒分段和恢复收据。候选压力前10秒中位23.60/25.20 FPS，仍未达标。
- `public/`：schema-2正式工具最终591项渲染、127项函数计时，70组/1,400对RGBA保持一致；包含当次manifest/生成类文本、完整路径集合和源码前后收据，两个运行日志无错误。计时总结同样使用完整12步窗口总量。此前585/121不与本项重复计作新增覆盖。
- `candidate_preflight/`、`comparison_preflight/`：候选单独及旧/新交替的两秒入口，资格均为false。
- `superseded/`：状态变量推断、过早读取Autoload/设置视口，以及窗口/逻辑视口混淆导致的旧QA记录。第二次渲染因重复已知引擎错误被明确停止；不称完整通过。

归档保留原始字节，逐项来源、大小及SHA256在 `archive_manifest.json`；生成夹具代码以 `.gd.txt`保存供审计，整个目录排除Godot扫描。本目录281份原始证据均按SHA256核对。真人体验、全关长时和最终性能继续按[路线](../../docs/POLISH_ROADMAP_20260906.md)推进。
