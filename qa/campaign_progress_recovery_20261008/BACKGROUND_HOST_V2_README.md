# V13 后台观察入口 V2

V1及其原来源/独立拒绝原样保留。V2只修后台配方与审查JSON的原字节绑定：一次读取raw，同时计算pin与解析JSON，解析后复核同pin，并在实际启动前重新核对所有来源、配方和审查原pin。原命令、Popen/finally wait、日志和退出记录以及完整61原执行器不变。

默认无--run只读预检，无进程/目录创建。--run必须新外层独立源码准入，随后原V13仍执行完整来源和原Native准入。两个全新外部无链接目录、真实wait退出码、hidden/shell=False及不直接Godot/不控制他人/不写原报告的边界保留。

后台只改善观察和退出记录，不保证系统或外部终止后存活；此前中断原因仍未知。任何外层host退出码不能晋升为完整恢复、19/UI/SDK、性能、设备或全目标资格，全部仍待对应原实际验收。
