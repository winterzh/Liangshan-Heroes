Windows Godot 4.6.3 Compatibility 用同一隔离档案运行两个进程，共 21 项通过，退出码均为 0，Godot 仍有 MSAA 和控件锚点警告。第一进程用正常指令在 102.33 游戏秒完成会合并通过暂停菜单保存。第二进程从主菜单继续，核对同一存档、会合事件、一名仍存活的原追兵、六名好汉、宋江与戴宗以及经济。白龙庙按钮显示已会合并只移动镜头。先令落单好汉从西巷归队，再正常收队和开船，114.87 游戏秒完成，演义 4/4。本轮仅覆盖隔离菜单和会合后的取样存档，公开入口与发行实测待验。[探针](menu_resume/probe.gd) · [报告](menu_resume/report.json)

## 登船点危险提示与触屏指令

行刑停止时，触屏目标提示选好汉后分别轻点解缚旗标。宋江或戴宗获救后，查看栏提示护卫开路，并按输入方式显示轻点或右键自己的登船旗标。到达办理范围后，若能看到实际阻挡上船的官军，查看栏优先提示清场。视野外敌人不在查看栏暴露；原 150 距离和两人分别登船判定继续应用。失败旗标可重试，清场不会自动登船。

一次 Windows Godot 4.6.3 Compatibility 隔离夹具，960×540、`TOUCH_UI=1`，13 项通过。使用实际江州战场和原有官军，将一名守军放在距宋江 115.38 的位置。四语的实际查看栏均显示风险；清空玩家视野后不暴露守军，同时登船仍受阻。原轻点命令进入办理，受阻后在新一次轻点才成功。戴宗仍留岸，键鼠提示右键。未复跑整关；手机、平板和发行包仍待验。[探针](boarding_controls/probe.gd) · [报告](boarding_controls/report.json)
