## 玩法变化

原有北面六人按固定槽位分成两队，分别沿法场—西巷—白龙庙—码头、法场—南巷—码头搜索。巡防营原有付费补军按生产序号加入对应队伍；原费用、训练间隔、资源预算、最多八人及拆营断援规则保持。没有增兵、瞬移、免费恢复或更改胜负。

每两游戏秒决策一次。追兵根据本队实际视距及目标可见性发现尚未登船的获救者，目标移动超过64像素才更新进攻移动，避免每帧取消命令。失去目标后前往最后目击地点，再从本路最近的后续路口继续搜索；不读取雾内伤员的新位置。至少三分之二存活成员到达110像素内才推进路口。抵达路线终点后只切一次守备，避免反复停止打断战斗。死者保留原槽，不把幸存者换到另一路。

首次解救后的20秒预警仍保留，文案说明分路搜索及断后/换路。顶栏改为行刑/解缚/追兵出动/登船进度，移除全知巡防补军计数。补给、两座接应营、获救者和原著演义合同不变。

显式保存包含两路游标、是否追踪目击地点、两个目的地及决策间隔；追兵引用固定保留六槽。江州恢复profile更新为`campaign_level2_v2`。组件验证拒绝越界游标及没有目的地的非初始游标。完整公开续玩仍须独立来源整合验收。
