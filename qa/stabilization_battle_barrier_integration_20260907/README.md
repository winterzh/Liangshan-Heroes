## 已验证的实际行为

- 官方固定30波开场，经正常 HUD intro/start 进入战斗；HUD当前子树信号与处理、
  相机和导航输入在捕获时关闭，未提交的手势清理，已有命令不回滚。
- 完成物理步后暂停，经过暂停帧的延迟释放，再同步捕获。两个真正效果退出
  回调各请求一次，HELD 前对象已释放，生命值和英雄伤害统计只结算一次。
- 箭矢由实际 physics 消费、飞斧由实际 idle 消费。HELD 五个真实物理帧中
  位置、寿命/elapsed、HP和时钟不变；释放后继续运行，无重复伤害或退出。
- 原有用户暂停在捕获释放后保留。新游戏缓存帧保持当前进程 Engine 域，
  恢复时钟合同保存独立步序号和缓存相位；不改变60Hz、delta或玩法RNG。

测试仅关闭两个新增夹具单位的自主 physics，其创建和所有伤害/效果消费者
均通过实际 Battle。未手动推进伤害函数、命中、寿命或效果 `_process`。
exit 回调的观察相位不扩展为所有引擎版本的伤害回调顺序保证。

## 仍未覆盖

脱树根绑定不等于世界恢复。现有 `_ready()` 仍初始化新世界，并拒绝直接走
恢复 RNG 分支；未来工厂必须保存已恢复时钟、同对象绑定屏障、完成世界引用
后激活一次，避免重复 deploy/on_start。完整世界、全部特效/死亡残留、任意
计时器/Autoload/战役协程、真实磁盘槽、退出重启和玩家继续菜单仍待实现。
当前捕获仅支持官方经典固定30波FIGHT，不扩展到AI、自定义或战役保存。

## 归档与复现

`SOURCE_PINS.json` 对每份归档给出原相对路径、归档相对路径、大小和SHA。
`.gd.txt` 是原始GD字节；在独立匹配checkout中按映射恢复名字后才能运行。
旧绝对路径仅为历史观察，不可当作新电脑的写入目标。候选 freeze 中的
scratchpad 路径与生产 before 均须保持匹配；源码升级后必须重新审查冻结。
`runs/` 保留原始 receipt/report/log、执行工具和原生 UID；不包含引擎缓存、
玩家配置内容或私有测试工程的完整重复资源。
