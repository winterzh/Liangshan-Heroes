## 失败尝试与修复

`attempts/` 保存初次脚本错误、未通关路线、教场缺陷及旧经济断言失败日志，不计入182通过项。

1. 初工具错误访问不存在的 `b._won`，甚至输出0断言的假通过；改查任务胜利事件＋END阶段，并加入预期断言数量核对。直接引用 `Unit` 常量也曾使SceneTree工具在autoload准备前编译失败，改用实例常量。
2. 攻击夹具摆位后尚未刷新迷雾/空间索引，点击变成移动；等实际可选后再发攻击。夹具和完整实战证据分别记录。
3. 演练骑用H再移动恢复了索敌姿态，导致它跑向枪手；改为避战。增加真正撤步和徐宁/钩镰共同攻击检查，站旁边或等骑兵离开不能领奖，复活教头可重试。
4. 早期整军回放不留建造预算、让宋江上前、拆营后直接去主阵或在敌将范围里持续送补兵，多次失败。修正测试战术为经营扩军、回防、安全集结与真实技能命令；共享战斗数值不随测试失败修改。
5. 旧跨模式检查假定“除祝家庄都不开经济”，新连环马因此被误报；按已接受玩法更新明确预期，再完整复跑39项。旧后四关逐剧情工具并未被宣称通过。
