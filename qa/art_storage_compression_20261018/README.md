每文件压缩前后逻辑SHA256/字节长/mtime均一致，重复路径0、SHA差异0。原PCK仍为SHAde6b7923817e697f35afdb51ffcef01f4f937ff98a736f54c55ea35122b908a0、1,249,383,508字节；压缩只改变NTFS存储表示，不是新导出。恢复命令为对清单每一精确路径执行compact /U（先确保空间足够），不需要还原文件内容。
