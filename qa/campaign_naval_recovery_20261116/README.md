## 玩家行为

备火仍消耗60木，仍将原刘唐设为登船状态，保留人口与唯一性预约。备火后增加“原船返港下船”：玩家需选择实际载着刘唐的船，驶到独立返港标记(20,52)，停留1.5秒。它与高俅交接标记(22,52)分开，避免重叠认领。未举火时由原火船返港；举火后由实际接到刘唐的阮小二船返港。

必须在标记64像素内、码头180像素内没有活动敌军，且码头岸上两格内有合法未占用空位。没有空位则可清理后重试，不扫描远处空地或把人传到内陆。回岸复用原人物实例，生命、成长、装备、冷却保留，恢复可指挥的守备姿态；不会重新生成英雄、回血或退还耗材。未使用的零人口火船退场；已举火的阮小二船保留，只移除载客元数据。

尚未取得两船安全撤离成果时主动下船，放弃本局火攻，锁定该分支；普通岸军、造船、基础通关和仍具条件的擒俘可以继续。已完成火攻安全撤离后下船，不取消演义成果。接应船/火船损失及第二批连船提前全灭，会停用已无法完成的火攻动作，但幸存载船仍可返港。载船真正沉没仍沿用刘唐失散、解除预约、忠义堂正常付费重练，不复活人或船。

基础胜利已可收兵后若生擒失去条件，任务明确可直接收兵，不继续指向不可完成的专船流程。增加10条四语并同步运行catalog；本批没有重新验证四语布局。
