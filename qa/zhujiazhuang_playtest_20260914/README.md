## 新手局会发生什么（重要）

我把**开局自带部队**直接 A 向南营，**没有先经营/补兵**：

- t≈10：探路完成，孙立到场  
- t≈151：仍未 `supply_cut`，出击 1 次，人口 15/20，金已积到 1550  
- t=171 起：**场上玩家作战单位 = 0**，此后只剩采金，金涨到 2682，顶栏仍「北矿待争」  
- 结局：未破外营、未胜，镜头落在无视野任务旗上，画面几乎全黑  

对照三计划自动回放：自动控制器会先 `_economy` 建筑补兵再出门，所以断援 3/3 胜；**纯开局兵冲南营 = 必灭**。

这是合理的难度，但暴露两点：

1. **损失后几乎无「该重建了」的强反馈**——人口/金在跳，没有明确败因句（如「作战部队已损失殆尽，请在兵营补员」）。  
2. **镜头停在迷雾虚空**只剩任务旗，玩家不知道该看哪——事件发生后镜头是否该拉回前营/来袭方向，值得评审。

## 和三计划对照是否一致

| 计划 | 自动回放 | 本次「新手冲营」 |
| --- | --- | --- |
| 断援 | 3/3 胜，出击 0 | 未完成断援即被灭 |
| 内应 | 3/3 胜 | 未测完（同前） |
| 扩矿 | 0/3 胜 | 未测完 |

结论：**「可读」达标；「有效计划」需要经营闭环**。开局兵一波流在当前守军强度下不成立，这与「位置/编队/补员有价值」的设计一致，但缺一条死亡后的再引导。
