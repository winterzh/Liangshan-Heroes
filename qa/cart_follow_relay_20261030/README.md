## 实现

原枣车目标固定取人物前方24逻辑像素，物件再按120px/s直线追赶，没有地图通行检查；靠岩坡可能把目标推入实心格，转弯追赶也可能直接越过阻挡。现在前方锚点复用原GameMap.limit_displacement，在阻挡前停住；当前到目标的整段可达便按原速度跟随，非直达才调用原land寻路，沿首段前进并再次做精确线段检查，无路则留在原地等待。只改变原枣车位置/渲染同步，不替换节点、不新增导航实体/缓存或改人物命令、速度、任务范围和货物记账。

原本已经处于非法格的旧物件是单独恢复边界：只移到人物一侧可直达的位置，再按可达路径跟随；这可能有一次纠偏，不把非法旧起点的修复伪称为正常连续移动。正常合法起点继续受原120px/s预算限制。0/负/非有限delta不移动，失配的empty_cargo字典和人物metadata不能移车。

原车交付/倒地已经保留现场轮角，但重新装载或接手时人物仍沿用自己上一辆车的视觉缓存。现在原_assign_loaded_cart绑定实际cargo索引和carrying_tribute后，从该同一原车接收有限轮角，再重绘。检查短黄泥冈、本人分层/变体/地图、原bundle/cargo关系和未交付状态，错误车辆/身份不接收。只写既有_tribute_wheel_angle视觉缓存；存档仍明确省略，显式恢复重建为0，不新增持久化字段。
