# 独立尾、蹄与完整坐骑停走比较基线

当前七层来自body_no_tail_v1、tail_v1、fore_upper_v2、fore_shin_v2、hind_upper_v2、hind_shin_v1、hoof_v1。本轮新增6份内置imagegen原PNG（含被替代的fore_shin_v1），目录累计14份。全部原字节保存，精确提示、输入角色及来源SHA见上一层prompt_set_v3.json。

四条独立腿沿LF+RH、RF+LH对角循环，蹄层与小腿分开控制；人工选定的两点蹄底参照在支撑阶段保持水平。独立尾画在腿后、无尾马身最后覆盖腿根，去除v3的矩形重绘。减速时收拢步幅，停姿躯干上提16源像素，随后恢复起步；这是预览模型，减速/起步不滑和真实碰撞未验证。

实际Godot 4.6.3导入和原生运行72项通过，四相、停止、再启动六张四向画面全部直接查看；停止时运动时钟暂停、16个模型蹄点落下，之后恢复换相。原检查/日志/图片在actual/，视觉范围另见visual_assessment.json。准备绑定的native_executed=false是执行前快照，不回写。

六图中未见v3的矩形切边或旧整图蒙皮大片拉裂，可作为骑手合成比较基线。完整蹄底轮廓接触、关节比例/根部透视与人眼连续自然步态仍需在合成中检查，不能从72项或六张截图推成最终动画通过。

下一步固定一次腰鞍对齐，骑手跟随同一躯干位移，重绑手/马口缰绳，比较站立、步态和停走，再接抽剑回收及实际Unit。实际章回、编译包和性能未执行，生产采用0；129运行/16保护/81外来及HUD零变化。原著身份限第54回，关节/鞍具/配色为美术补足，全库美术目标继续。
