## 开发过程与失败

`behavior_attempts/` 保留全部 V2 真实运行，包括明确类型解析、过早加载生产类、无效 SubViewport 属性、错误预乘白中心阈值以及真实释放目标失败。即使某份不完整报告显示零 FAIL，日志存在脚本错误仍是失败；最终临时 V2 `20260906T095957788498Z` 360 次通过。旧 Settings 的早期原目录受控对照 `20260906T095551754038Z` 为 28 次，源码精确恢复记录在 `application/legacy_20260906T095551470993Z/`；最终公共入口改用私有副本，不再交换当前生产文件。

`gui_attempts/` 保存 WeakRef 解析、滚轮落点修正及模态层级修复前后的证据。最终临时四进程 `20260906T095129838925Z` 332 次通过，但最终结果以新的公共来源复验为准，不把两组次数相加成覆盖率。`application/` 是本轮逐次应用/恢复收据，`investigation_sources/` 是当时准备和串行助手，包含历史假设的草稿不能替代当前公共说明。

所有行为测试都是明确夹具范围，不等于完整战役玩法一致、三名真人体验、长期稳定、性能达标或发布许可。压测自然伤亡、音频全局随机流和按呈现帧触发的伤害仍有非确定性。
