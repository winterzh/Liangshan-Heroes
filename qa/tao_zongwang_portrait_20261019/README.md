# 陶宗旺铁锹头像候选

本批使用内置imagegen生成[独立头像原PNG](native_originals/portrait_v1.png)，精确参数见[提示词](tool_prompt_portrait_v1.json)。原图逐字节复制，无本地重绘、抠背景或重编码；旧九宫格/身体/生产路由保持。静态对照见[可打开比较页](readability/review.html)及[实际截图](readability/review.png)。

## 原著与解释

本次实际抓取维基文库《水浒传》120回本第41回，完整文本及抓取来源保留。原文第31行介绍“第四个好汉姓陶，名宗旺，祖贯是光州人氏。庄家田户出身，惯使一把铁锹，有的是气力，亦能使枪抡刀，因此人都唤做‘九尾龟’。”第38—39行诗句“宗旺力如猛虎，铁锹到处无情”“神龟九尾喻多能”进一步支持人形与铁锹，不把绰号画成龟甲/尾巴。精确引文与行号见`canon_basis.json`，完整文本的标点/引号以该文件及原文为准。

旧头像测量路由为portraits15的[786,401,414,377]，工具画成锄形横头，现用走图则为铁锹。新稿保留既有褐衣、灰褐头巾、壮实面容/短须的身份参考，改用与走图同类铁锹，纸纹背景和近景构图延续独立头像方向。须发、年龄、肤色、衣色、具体锹刃和肩侧持法均为美术解释，原文没有逐字规定。

当前技能中的黏胶/背甲等文字与效果另有待审快照，本批不修改或批准它们，也不称陶宗旺的全部原著问题已经完成。

## 实际验证

隔离已有Edge/私有Playwright 1.64.0实际显示原头像、候选和走图首帧，并显示256/128/96/64/32像素比较。13个显示实例共享3张实际解码原图，浏览器WebCrypto摘要与三个源文件一致，截图1800×1450，页面错误0，独立profile进程已退出。未修改用户登录profile或系统配置，依赖/profile不进入Git。

原稿及比较图已直接目检：64像素下大脸、头巾、须形及锹刃轮廓较清楚；32像素只可判断粗轮廓，不接受凭五官可靠认人。旧取图区有上下邻图窄条，比较页按真实现用矩形显示，没有裁掉掩盖。新图头巾/工具完整，但外侧留白较提示要求小，游戏边框裁切仍待原生UI验证。

这是来源与静态阅读候选，未接入Godot、图鉴/HUD、真实单位或包内，没有性能/小分辨率/多语言/跨设备资格。生产采用0。129/16/81与HUD、26份其他待验证本地文件保持，原Godot单一队列和外来占用标记未动，全库美术继续，main/Steam未操作。

## 复现

`render_readability.py`默认只写全新工程外目录，不覆盖旧输出：

```text
python -X utf8 -B qa/tao_zongwang_portrait_20261019/render_readability.py --deps <私有Playwright目录> --output <全新工程外目录> --browser-exe <已有Edge路径>
```

需要已有Pillow与Playwright；原文抓取另用已有BeautifulSoup。源图、原文与提示可通过各JSON中的SHA复核；归档索引保留原执行脚本、HTML、截图和收据的摘要，原始公开HTML也保留。旧图、任何失败记录与原始来源均不覆盖。
