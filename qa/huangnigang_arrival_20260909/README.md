## 失败与修正

1. `20260909_143823_8b2868e3`：入场63项及八关启动合同通过，但散位七人硬冲已到齐押队全部阵亡；酒计夹具仍把纲担留在东口，吴用被挪到东口模拟缺席时触发了真实疑心规则，导致后续断言连锁失败。保留原日志和报告，不计最终通过。
2. `20260909_150043_4e53ca6d`：补上能检测原始 `market_stall(...,"wine")` 的配置/实际节点正反夹具；酒计夹具改为明确的正常到冈布局。真实强夺采用集合后迎击，72项入场和61项路线/边界通过。
3. 独立审查发现基类仍按旧 `TOP` 距离判断到达，杨志新终点距它186.6、大于110，标准版会卡住。最终将行军推进合并到基类，加入直接使用基类实例的反例夹具，并复跑当前入口两条完整路线。初始镜头经两次图审改为商客歇脚处。
