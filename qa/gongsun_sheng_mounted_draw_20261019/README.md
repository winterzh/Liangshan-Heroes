# 公孙胜分层剑臂与取剑/回鞘原型

本次GitHub同步只包含已目检的原稿、精确来源与已执行来源检查工具。本地rig_v1/rig_v2原型及准备脚本正在等待原生执行，尚不纳入本次同步；上文档提及这些名称只是本地工作状态，后继随实际收据补齐。native_pending_at_source_sync.json仅记录原稿同步时观察到的活队列，不是之后的活跃或通过证明。

本轮内置imagegen原稿、精确参数与来源SHA在prompt_set.json、tool_prompt_*.json、source_*.json。八份原PNG保存于native_originals/，无本地像素修改；六份用于组装：固定衣身torso_v1、闭合上布袖upper_arm_v2、forearm_v1、hand_v1、sword_v1和空scabbard_v1。clear_v1整人过渡稿引入身体/鞘口漂移，upper_arm_v1多带袖口/肩甲状边缘，均不选。

衣身保留一只持缰手，另一只剑臂分上臂、前臂、手组装。只绘制一个完整剑图层与一个空鞘图层，鞘口固定于背部。拔剑沿鞘轴平移，鞘内部分用运行时半平面纹理裁剪隐藏；剑尖完全离鞘后才转向指敌，回鞘沿对应路径返回。袖臂使用人工固定关节与一次宽度标定，原PNG字节/RGBA不改；不能把骨长或裁剪数学当成手指握持、布料接缝、全路径净空或原著动作的证明。

rig_v1只完成冻结准备，静态复查发现return_clear到partial_in段漏用鞘口裁剪，没有执行；rig_v2保留旧快照并修复该区段。准备绑定里的native_executed=false保持执行前时点，实际执行与目检以独立收据为准。原型不接生产Unit，不改战斗、剧情、HUD或其他人物。

依原著第54回冠服、短须绦、背悬单柄松纹古锭剑和黄花马、举剑指敌身份。动作分层与取剑/回鞘时序为游戏美术补足，不增加小说剧情、伤亡、武器或其他章回技能。完整连续画面、剑/手/鞘遮挡、实际Unit、适用章回、编译包和性能仍须验证，全库美术目标保持开放。
