## 问题与修改

上轮只镜像门图，未将图中石墙脚与场景寨墙端点对齐。本轮 `campaign_gate_visual.gd` 用两个源图脚点构造绘制变换，映射到中心两侧各64逻辑像素的墙端；竖直方向保留，阴影用同样接地点。只对本关两门启用。入口箭楼沿内墙错开到(17,30)/(17,20)，共享数值保留。

群选33人、孙立为最后一位，右键接应标记：旧阵型让孙立停在距标记约87.79像素处，而办理半径64；到达凭证过期后永不触发。`contact_before.log` 和 `contact_probe.gd` 保留这个输入复现。修复后，实际非排队地面右键命中旗标时，仅将选中且有资格的办理人以标记中心为落点，其余成员使用原阵型。到场仍必须维持5秒，不自动挑选未选单位，不把A/H/S、普通途经或攻击当作剧情命令。

新增人物定位、错人解释、需要停留的秒数，以及孙立死亡/偏门已经强攻破坏时的后续指引。不再让不可完成的标记留在场上或误记成功。标记附近树木、敌军、驻扎/维修命令仍按原输入优先级处理。
