开局绘制调用降低约 57%，宿主渲染 CPU 降低约 59%。岸线原配方 1080 个指令变为 1 个提交；台地 1414 个指令变为 495 个保序提交，其中 34 个纹理矩形仍原生绘制。两个缓存均有效，不是回退路径。这里的“指令/提交”计数不等于后端统计的实际 draw calls。

未关闭岸线、台地、阴影、芦苇或建筑来取得收益。GPU 计时为 0 是不可用；渲染 CPU 可能包含驱动等待；帧间隔原始序列保存在各 `opening-render.json`。这组冻结模拟仅用于定位/复验绘制成本，不是 60 波实战、冷启动速度或长局性能测试。测试顺序为各分辨率旧→新，每个场景两次，不宣称随机化统计实验。
