# 索敌候选 QA

基线 bf3e1a6；生产仅 Battle 候选收集和 Unit 索敌入口。[实现、计时表和复现](../../docs/ENEMY_CANDIDATES_20260906.md)。

- `enemy/` 专项 68、`ai/` 173、`chase/` 44、`grid/` 142、`ranged/` 23，共 450 项；五个最终报告 passed=true，六次进程日志均无脚本错误。
- `stress/` 无插桩正常战斗原始帧时间及采样末尾实际画面；`runs.json` 记录进程参数、时长及生产/入口源码哈希，`runner.py.txt` 为本轮运行记录。
- `live_distribution/` 约 10 秒正常战斗候选分布计数、探针与恢复收据。记录 calls/raw entries/returned opponents，不把条目比值当耗时收益。
- `preliminary/` 初步候选探针、六组配对窗口、第一次无脚本错误的专项日志；最终专项进一步显式直接比较目标对象，报告位于 `enemy/`。
- `fixture_errors/` 两次测试场景初始化错误单列，均已修正并完整重跑，不计入最终通过数。
- `diagnosis/` 前置分段计时和探针原始记录。嵌套成本不可相加，诊断并非性能验收。所有临时生产插桩已恢复；本机路径只属于历史运行记录。
- `receipt.json` 按 LF 的生产/测试源码哈希和原始证据字节哈希；目录属性在首次暂存前建立，禁止把运行期 Godot 缓存混入。

正常驻守战预热 3 秒后约 10 秒计数：6,678 次索敌，4,712 次邻格只有友军（70.6%）；原始邻格条目 924,570 个，进入后续过滤/评分的候选 6,280 个，减少 99.3%。混合组中绝大多数也是友军。此为一次实际战斗的插桩分布，不能直接换算耗时或 FPS。

最终无插桩正常驻守战 250 帧 / 10.004343 秒 = **24.99 FPS**，P95 76.973ms、P99 92.918ms、最慢 98.483ms；结束 141 单位，缩放 (1.091565, 1.091565)。Godot 4.6.3-stable (official) / NVIDIA GeForce RTX 3070 Ti / forward_plus / 1440×900 / 1 倍速，布置 200 敌、预热 3 秒后采样约 10 秒。截图为采样末尾画面，瞬时读数不等于窗口均值；没有相同战斗重放或足够多配对整局样本，不能用相邻批次帧率差宣称整体提升。整体性能及长时、真人八关/驻守验收仍开放。
