## 玩家变化

- 新增南门外接应集结定位，点击仍只移动镜头，不自动调兵。
- 顶栏显示牢内实际就位0/2与门外有效接应人数/3；查看三名内应、吴用、鲁智深或武松，可知是否缺指挥者、同伴、牢内就位或时迁乔装。只是准备信息，不披露雾内守军。
- 接应人数由原夺门动作的筛选条件抽取，界面与实际动作共用。排除死亡、剧情离场、被俘、驻军、眩晕、缴械、非战斗和不在名单内的单位；保留180像素范围及原三人要求。鲁智深/武松身份提示对应原动作的办理角色限制。
- 任务随局势显示两线筹备、牢内待机、自选举火、火号接应、窗口结束后的重整、内应阵亡后的强攻、救出但城门未开、已撤出人数。只更新标题和正文，不重建动作或清除办理进度。
- 提前举火仍允许；90秒结束后原夺门动作仍可办理。伤员查看明确不参战和二人均须撤出，不派遣或瞬移。

全部信息由已有单位、事件及关卡字段派生，无新增保存字段，level8 profile仍为v1。生产内容身份变化，旧冻结候选资格不继承；当前战役公开续玩未因此开放。
