## 复跑

准备好当前工程的Godot导入缓存后运行：

```powershell
python tools/run_campaign_squad_qa.py --godot <Godot可执行文件绝对路径> --lock <本机共享引擎锁绝对路径>
```

锁应与同机其他任务使用同一路径，父目录须存在。工具只结束自己启动的超时子进程，不清除他人锁；输出在被忽略的 `.godot/squad-qa/`，不访问真实玩家存档。此复跑包装器在通过后整理入库，本次9.68秒结果来自相同场景/环境的本机运行器，未声称重新测试了包装器。
