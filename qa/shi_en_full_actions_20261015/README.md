# 施恩三类动作接入与真实回调验证

新增普通施恩四向攻击、受击恢复和倒地，与已有待机/行走合为五类动作。13张运行PNG/12份方向资源/40个新姿势保持原生来源；生产接入内容和限制见[实现说明](../../docs/SHI_EN_FULL_ACTIONS_20261015.md)。

`native_pass/`为实际通过批原始证据：117项原生导入检查、376项场景检查、三尺寸81张图，导入/窗口退出0错误0。先核对原Level7非战斗施恩，再用实际驻守战普通战斗定义和显式靶子检查真实攻击伤害、受击恢复的物理推进、四阶段死亡、末帧及正常消失。非参与者/Battle模拟冻结、测试迷雾关闭；不授予鼠标输入、全关或完整游戏资格。

`visual_review.json`记录直接查看的15张最终画面及SHA。`adoption_receipt.json`绑定41个运行文件与通过批字节一致、5224项输入、13个新UID无冲突，以及原单位/地形/景物保护。全部原始通过图与日志完整归档，`archive_manifest.json`逐文件绑定外部原件。

`native_prior_cases/`保留alpha浮点比较误报、错误靶子/章节定义两个失败批的原报告，以及375项真实回调通过但画面被旗遮挡的旧批。`case_context.json`说明分别修正的原因；旧报告未覆盖。最终空地避开景物，原旗帜没有隐藏/搬动。`runtime_plan_initial_corner_assumption.json`保留第一次布局计划；新计划增加原角点alpha字节和确实全透明位置，PNG不改。

`runtime_plan.json`和生成清单中的未接入字段是候选/导入阶段记录，后续接入事实见独立收据。`build_shi_en_full_actions_20261015.py`默认只读核对原字节与几何；候选构建运行器不能覆盖已接入资源。外部原始工程包含当次完整冻结源码和各失败/通过批全部PNG。

PCK/SDK/Steam、近距离头像、连续动作审美、960窗口文字与其他角色/环境/特效/UI仍开放。此批不是完整美术验收或发布。
