## 修复的界面问题

主菜单较长英文说明曾把最后一项挤出窗口；现缩紧入口间距、调整按钮高度并提供滚动兜底。驻守、选关、自定义配置等长弹层可滚动，返回入口固定可达。编辑器顶栏和单位分类可换行，工具栏独立滚动，名称列对齐；选择提示、场景主题和波次规则补译。内建名称显式翻译，自编名称不再被按钮、OptionButton 或 PopupMenu 二次翻译。长结算说明换行，战绩列表占用剩余高度，底部按钮保留空间。全页弹层实色遮罩避免底层文字干扰。

`before_main_menu/` 保留校订后英文说明造成的 1 项布局失败及 13 条重复发现；`before_settlement/` 保留三个模式长说明的 3 项失败。`ui_independent_review.md` 记录独立复核发现的分类漏译和自编名字碰撞，最终回归已加入这两个边界。历史失败不并入最终通过计数。
