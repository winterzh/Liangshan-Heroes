# Battle root R1 module — R2 actual smoke preparation

This R2 harness is prepared only; it has not run in Godot. Its parent R1 actual run failed with no final report, so no successful root restore is claimed. The
module under test remains the exact frozen `scratchpad/run_battle_root_state_r1/root_state.gd`
raw SHA `3a758cdb6f0e6b7eb30ff83c2b6b9f01cb97742f26c9513fc89ee9b566d11c6f`.
Battle is `07d7cb179642b3b6b5716a7e290c24a3c54f586ea39460f7905ba778ca202efd`;
provider R2 is `a78dc5e9895cc4bf381e4c368c51527075ce5afa5835531881faa3a99d71077f`.
No tested module, production, old receipt, or old harness is changed.

The real installed provider resolves its identity before any fixture is built.
Its eligibility and actual engine executable SHA must agree with the host. Only
this returned trusted content version enters Factory capture/validate/bind; no
save compatibility value or invented executable identity supplies trust.

There is one ordinary `scenes/main.tscn` Battle. Its real `_ready` deploys standard
30-wave skirmish; the fixture invokes the original `_on_intro_done` once, which
starts its original Level, including the original initial gather commands. This
is a **new-game capture fixture**, not a restore method. The tree is truly paused,
Battle disabled, pointer input absent, and process/deferred work drains before
capture. No await occurs between a successful capture and its corresponding bind.
The first capture requires the untouched default Rect2. The second obtains a
nonzero rectangle from the original `_grid_build`, using the actual viewport and
RTSCamera. The third is an explicit fractional/negative-size transport boundary;
it does not call `has_point` on a negative rectangle.

The exact frozen classification must still be 169 declarations = 104 root fields
+ 65 external fields. Every one of the 83 ordinary values receives an independent
real codec audit, with only Rect2 converted to the documented position/size pair.
Every one of the 104 root fields is individually checked after all three binds.
Normal values compare native types and exact values; arrays and dictionaries
preserve ordering and duplicate entries. Clock fields verify the specified origin

All three input timestamps must use one observed bind-time origin. Each bind
checks the returned physics/process frame immediately. This proves only the root

simulation phase/order.

The entire live Unit set under the real source units_root is registered in the
production shared identity module, including resources/buildings. New real Unit
shells represent those stable identities in the destination; their local values,
inventories and gameplay state are not restored. This is not UnitGraph integration.

After the default case, explicit root fixtures add nonempty selection/groups with
duplicates, none and expired entries, two blocker entries with remaining budget
three, live-native-ID caches, and a nonempty economic cache. No cache is cleared to
make validation pass. A retirement snapshot with a UID above 2^53 exercises exact

of complete graph consistency or actual player command reachability. The shared
expired Unit tombstone stays live through every bind and is freed only after all

The normal rectangle case checks actual original inside/outside consumer results
before comparing the restored consumer. Six separately JSON-roundtripped malformed
