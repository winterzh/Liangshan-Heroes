## 改动与玩家操作

选择钩镰枪手/徐宁，或查看可见的十二骑之一，可在原单位信息栏看到战术提示。甲马显示当前连环来源实际减伤、近身有效搭档0/2—2/2，以及当前缺少的条件：受阻、搭档或近身攻击目标；已破阵显示可以集火。钩镰单位有可见甲马目标时显示该目标状态，否则提示两人配合与徐宁可充当搭档。视野外甲马只显示情报不可用。

`hook_conditions()`由原有破阵逻辑抽出，模拟和查看共用同一判定。保留96像素、路径可通、失能/驻军/被俘排除、芦苇/沼泽或temp_speed<0.8、两人中至少一人近身锁定目标的原规则。没有新增伤害、人数、资源、免费单位或自动命令。提示只读，不增加Level/Unit存档字段，既有profile结构保持；生产内容身份改变，旧续玩候选资格不继承。

共享HUD仅在关卡提供`unit_tactical_hint`时追加文字，目前仅level4提供。新增9条中文键对应英/日/繁中翻译，来源`campaign_hooks.json`与运行catalog一致。
