# 黄泥冈推车轮转与下一步提示（2026-10-30）

本批为既定计划中的小批次开发：复用已采用的人物和车轮原图，不生成或修改位图。

## 实现

- 晁盖、吴用的既有分层推车接入真实位移驱动轮辐，保留每个人原有的车体位置、人物步频与独立视觉轮角。阮小七作为同路径回归对象。
- 只在本人第十六回载货身份启用。停车、动作受击和卸货时不新增轮动；原空枣车仍使用现有物件。
- 运输阶段新增“下一步 · 当前所选”：选中一个有待办的七星后，镜头定位其当前取车、装货或出冈标记，并显示对应提示。它不发移动命令、不请求任务、不自动装车或交货。
- 运输阶段的空手选择排除白胜，收队阶段仍可选中白胜。新增提示包含简体、繁体、英文、日文。

## 必要验证

`probe.gd`只覆盖本次三名分层推车者与选择提示：实际关卡原任务回调、三阶段导航、四向轮相位画面、实际Unit移动、停车/受击/身份拒绝/卸货、既有视觉轮角恢复，以及四语按钮和提示。原药酒前提、取车/装货摄影位置是显式夹具；不属于普通键鼠完整通关，不重跑全量52/61、八章或发行测试。

运行入口复用原生产冻结/导入工具，再使用本目录的独立驱动：

```powershell

python -X utf8 -B qa/huangnigang_production_20261020/run_batch.py import --run <本次冻结目录>

```
