## 行为

第三批六艘原船中的末两艘承担护航，其实体、所属批次、战斗数值和胜利计数不变。其余四船与岸军照原计划出击，座船仍在原540秒时点发令。护船先靠拢座船两侧前方，出发后目标由座船实际位置派生；座船被制服停航后仍保卫附近水面，真正沉没/失效才向已知前港推进。没有瞬移、额外船只、回血或根据玩家迷雾位置发令。

目标仅在座船附近有限偏移中找可容纳船身且水道连通的位置，不全图搜索远处水域。近处可见交战和Unit嘲讽优先；目的地未变化时不反复重发，抵达后清除旧攻击移动推进并守备。角色由原water_groups[2][4:6]、waves[2]和flagship引用派生，没有新增Level字段/计时器，普通Unit命令按已有框架保存。源码身份改变，不沿用冻结候选恢复资格。

两条四语包括敌船查看说明和第三批出发通知。原通知固定“两艘随行”会在玩家提前击沉护船时失实，最终只修改为提醒留意护船位置并选择接战方向；运行期间已加载的来源在live/level.gd.txt保留，字节比较证明最终Level仅替换这一条通知文字。两份翻译和catalog一致，换行/占位符检查无误。
