## 证据与复现

`native/` 保存原生测试，`export/` 保存导出与身份验证，`guards/` 保存外层保护和实际 EXE 短测，`visual/` 为六张原字节 PNG。`source_mapping.json` 逐项记录原路径、原件和归档的尺寸/SHA；真实玩家文件清单不归档，只保留原件摘要和保护相等结论。含本机路径的文本仅替换路径占位符，其内部哈希仍引用原始运行文件，不应拿脱敏副本哈希代替。

复现须使用上述 Git 源码、固定 Godot 4.6.3 和依赖，先确认共同引擎槽空闲。正式工具 `tools/run_steam_integration_qa.py --run --native --visual --profile-root <新的短绝对根>` 产生本轮全新 QA 后，运行 `tools/build_steam_candidate.py --run --qa-run <新 QA 目录> --profile-root <短绝对根>`。`helpers/` 保存本轮外层守护、EXE 短测和白名单归档脚本的文本副本，恢复时需将路径占位符替换为本机配置，并使用全新忽略目录。归档脚本不会上传 Steam，且拒绝复用输出目录。
